This standalone test compiles the repository's actual `HybridLumenGIReceiverTemporal.hlsl` helper into a small compute wrapper, executes its DXIL on D3D12 WARP, reads back results after a fence, and compares them with an independent double-precision source-geometry oracle.

Run `Tests/Validate-ReceiverTemporal.ps1`. Existing Windows x64 VS2022, CMake, DXC and Node are required; the script installs nothing, changes no persistent environment, and builds only in a unique TEMP directory. Exit 2 means the WARP environment was unavailable and is not a pass. Reports bind source and executable/DXIL/input/output hashes and retain invocation logs.

The 2,179 cases cover the actual helper's eligibility and history-key predicates, both halves of the 64-bit key, primitive mismatches, sticky conflict, flags, nonfinite values, degenerate normals, column-major matrix memory, and 2,048 deterministic source-transform cases. Expected previous points and normals are reconstructed from previous object geometry using double precision and inverse-transpose matrices; they do not duplicate the helper's normalized matrix-vector normal operation.

The CPU owner permits relative positive similarity transforms. Constant nonuniform scale or a constant mirrored source is included; changing nonuniform scale and relative reflection are rejected through the supplied CPU eligibility flag. The helper trusts that flag. This test does not establish support for arbitrary affine normal transport, pixel identity rasterization, Unity per-draw bindings, RenderGraph/UAV ordering, or a physical GPU.
