This standalone test compiles the actual runtime `HybridLumenGIHardwareNormals.hlsl` into DXIL, executes it on D3D12 WARP, waits for a fence, and compares readback normals against a double-precision source object-to-world covector oracle. It also executes the previous interpolation order on the same inputs to reproduce its nonuniform-scale error. Source contracts check that `HardwareTrace.hlsl` calls the executed helper while preserving geometric/front-face identity and distinguishing unavailable source normals.

Run `Tests/Validate-HardwareNormals.ps1`. Existing Windows x64 VS2022, CMake, DXC and Node are required. The script installs nothing and builds in a unique TEMP directory. Exit 2 means WARP is unavailable and is not a pass. Reports retain command logs and source/DXIL/executable/input/output hashes.

The 4,183 cases include 4,096 deterministic nonuniform, reflected and sheared source transforms; large/small finite scales; missing, zero and nonfinite source normals; nonfinite matrices and weights; and degenerate interpolation. The tested contract normalizes each transformed vertex before interpolation, as URP 17 Lit does. Raw geometric normals and side policy are outside this helper and remain unchanged. The test does not validate Unity import, actual RTAS/candidate execution, normal-map textures, half precision raster interpolation, driver-specific DXR behavior or a physical GPU.

Official reference: Unity Graphics commit `feb4de2d9a93a4ae10d287d3a6d7003d08ea3e53`, `Packages/com.unity.render-pipelines.universal/Shaders/LitForwardPass.hlsl` (`LitPassVertex`, `InitializeInputData`) and `ShaderLibrary/ShaderVariablesFunctions.hlsl` (`GetVertexNormalInputs`). The helper independently implements the operation order; no external source is copied into this test.
