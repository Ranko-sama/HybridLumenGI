# 真实两面墙的有限缓存反馈

2026-10-29。产品来源仍为 `269241b38c45a97f29758fb92640cdb36f5092f8`。本项没有新增 Runtime 改动，也没有使用 Codex with ChatGPT。它把此前的独立单次反弹和屏幕历史响应继续推进到实际表面卡片、图集、双缓冲世界缓存与同帧 gather 的反馈链。

第二次原生采集通过：固定 34 帧完整 URP 渲染、6 份缓存比较、54 个 gather 比较均符合运行前冻结的独立参考。第一次采集因观察器超过 Unity 的 UAV 上限而失败，完整保留；第二次只拆分元数据采集入口，数学、图集资格、屏幕输入资格和误差合同保持相同字节。

## 有限物理输入

两面 1×1 的垂直有限墙位于 `x=0`、`z=0`，分别朝 +X、+Z；每墙一个真实 chart、一个缓存 patch。普通 URP Lit、金属度 0、无贴图/发光，线性 MPB 颜色为 A `(.5,.25,.125)`、B `(.125,.5,.25)`，漫反射率为 `(.48,.24,.12)`、`(.12,.48,.24)`。

白色方向光强度 1，方向严格为 +X，所以只有 A 有直接漫反射源。普通 90° LookRotation 在本机留有微小方向分量，准备阶段改用精确的单位四元数，并在实际运行前检查方向分量，避免把 B 的微弱直照藏进误差界。

640×360、cache 每 patch 16 条射线、gather 每像素 8 条射线、ray bias .03、距离 20、feedback 1；环境、屏幕追踪、guide、发光采样、clamp、temporal 和空间滤波关闭。先固定 32 帧关闭光源，验证已经测量到的有效黑色缓存，再通过普通 Light.enabled 开灯，只执行两次更新。没有清空缓存来模拟冷启动，也没有根据 RGB 改变样本数或延长窗口。

这是两次带历史混合的 Jacobi 更新：第一次开灯缩短旧缓存历史到 1 后提交样本数 2，混合权重 1/2；第二次提交样本数 3，权重 1/3。第二次缓存最多含 2 次前置漫反射散射，同帧 raw gather 最多 3 次，若再乘可见接收面的反射率则最多 4 次；不把“更新两次”称作纯粹的两次反弹。

## 参考与来源

独立参考仅消费实际采样方向、偏移原点、几何图集、卡片/owner 身份、标量历史和变化输入，自己计算有限矩形交点、缓存连接及递推。产品的 hit、PDF、权重、cache RGB 和 raw RGB 不作为期望答案。先完成输入资格并写出完整期望文件，之后才读取独立保存的颜色观测。

三个观测窗口为逻辑帧 31/32/33。缓存读入缓冲在更新后逐字节保持不变，下一帧的实际读入缓冲逐字节等于上一帧写出缓冲；同帧 gather 在更新之后记录。三窗的卡片、owner、索引、anchor、mask 和几何图集保持一致。原始参考、17 项 CPU 检查、编译与运行来源均有哈希记录。

数值比较按 source rho、normal、cosine 权重、单 tap 乘除、射线累加、除法、历史 lerp 和最终 half 存储逐层传播界，未用观测残留拟合容差。当前几何资格明确使用预声明的 `64 × 2^-23 × scale` 命中位置范围假设；它是有限输入一致性检查，不能充当所有 DXR 硬件的 RayT 精度定理。CPU 三角绑定和 GPU 卡片身份也不等于逐射线导出的 committed-hit 记录。

全部 6 份缓存与 54 个 raw gather 比较通过。额外除以 π、交换颜色通道、未知置信度和错误的零反馈缓存负例均被参考判据拒绝。期望文件 SHA256 为 `23fb8ccdfd07a67aafc3e8da48cb61ff0a1ae1600e6f6255d81d755656ce017f`。

第一次原生运行在第 32 个黑帧报告 metadata kernel 的 9 UAV 超过 Unity 支持的 8；显式 DXC 和独立编译成功不足以证明 Unity 接受这一绑定。尚未开灯，没有生成颜色通过结论。第二次使用 8 UAV 的 metadata 和 1 UAV 的 changes 入口，另外三个入口各 1 UAV；实际编译反射、两程序集预检与原生执行通过，第一次失败未覆盖。

第二次 34 次请求与四类相机/上下文回调全部闭合，native exit0；112 个产品源和 9 个临时文件已核对并恢复，既有工程场景及设置保持一致。首渲染 2.3203 秒、采集段 3.1988 秒，这不是性能或首次使用延迟验收。
