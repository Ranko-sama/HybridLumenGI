# 当前支持范围的画质验收判据

2026-11-04，用户授权主线程参考 UE5 及相关实时 GI 项目，自主决定画质取舍，后续不再等待用户提供误差数字。本页记录本项目的工程判据；外部实现不提供本项目的通过证据，也不替换原 G0–G5 条款。

适用于原计划承诺的普通不透明 URP Lit 漫反射 GI。既有 960×540／30FPS、GI 三段逐帧合计 p95≤25ms、进程 local 有限采样峰值≤1GiB 目标保持。画质改善须同时满足成本约束；不通过提高曝光、间接强度或无限延长历史掩盖问题。

## 一手依据与推导边界

| 已核查的一手资料 | 可用于本项目判断的事实 |
| --- | --- |
| [Epic：Lumen Global Illumination and Reflections](https://dev.epicgames.com/documentation/en-us/unreal-engine/lumen-global-illumination-and-reflections-in-unreal-engine) | 多级缓存以更新延迟换性能；局部变化通常较快，全局变化可需数秒；加快更新或减少噪声会增加成本。其艺术性颜色增强也可能非物理，展示画面不是线性颜色真值。 |
| [Epic：Lumen Technical Details](https://dev.epicgames.com/documentation/en-us/unreal-engine/lumen-technical-details-in-unreal-engine) | Surface Cache 覆盖和内容制作有条件；快速相机移动可使间接照明更新落后。这样的已知限制应说明，但不能据此自动放行本项目的冷入空档。 |
| [Majercik 等：Scaling Probe-Based Real-Time Dynamic Global Illumination for Production，JCGT 2021](https://jcgt.org/published/0010/02/01/paper-lowres.pdf) | 第 4.2–4.3 节区分亮暗过渡、照明与可见性历史，提醒 TAA 会增加收敛滞后。论文内的变化阈值和加速窗口是算法参数，不是本项目验收门槛。 |
| [NVIDIA：NRD 官方文档](https://github.com/NVIDIA-RTX/NRD) | 主历史与快速历史在降噪、滞后和偏差间取舍；累积帧数应对应实际渲染帧率及时间，而非帧生成后的显示频率。 |

以下 10%、20%、0.05、1／2／5 秒是主线程自主制定的本项目起始工程目标，**不是 UE5、DDGI 或 NRD 的官方标准**。选择圆整、可解释的误差和响应区间，用于决定是否需要具体修复；没有逐帧临摹 UE5 的含义，也不将既有采样点反推成阈值。

## 判据

| 项目 | 当前采用的工程目标 |
| --- | --- |
| 静态颜色与能量 | 在事先定义、材质和物理量匹配的接收域，区域平均亮度偏差绝对值≤10%，归一化平均 RGB 的色向 L1≤0.05；逐像素亮度 MAE／参考区域平均亮度≤20%，并检查局部漏光、串色和结构错误。平均值通过不能抵消可见错误。 |
| 局部换色／关灯残留 | 预定接收域内，能独立识别的旧光分量均值在事件后 1 秒≤原均值的 5%，2 秒≤1%。平均达标不能抵消局部明显残留、串色或结构错误。这判断旧光消退，不等于新颜色已正确。保留的发光面、环境和原生直射不能算作旧光。 |
| 收敛与恢复 | 局部事件后 2 秒、全局事件后 5 秒，间接光应进入匹配最终状态参考的亮度±10%、色向 L1≤0.05 范围，并保持至少后续 0.5 秒。当前定义是可用响应时间，不要求数学上完全归零或无限阶精确解。 |
| 运动颗粒与拖影 | 继续使用已授权的取舍：相同路线和曝光下颗粒明显减少，允许适度柔化，旧门轮廓不能明显加重；普通播放不能出现持续可辨认的第二道门形。新显露表面不得把已确认属于另一表面的历史当成当前已知值。缺少全过程证据时保留范围，不因四张图宣布全段通过。 |

10% 亮度差约为 0.14 档，是本项目可先接受的有限偏差上限，不是人眼不可察觉界。色向 L1 是当前已有的通道比例指标，不冒充感知色差 ΔE。20% MAE 限制均值相抵掩盖空间误差；它与同曝光结构判读一起使用。

参考亮度接近零时，不使用不稳定的相对百分数：零漫反射／黑室按既有绝对辐射与来源分离合同判断，动态关灯残留按事件前同域的有效旧光分量归一化。未知点单列，不能以黑色填补或通过删除未知区域改善结果。参考采用已有有限近似即可，保留采样、截断和模型不确定性，不要求重启严格误差证明。

## 结果如何使用

- 相同物理量、同场景／配置的现有结果可直接复用；不同版本保留原归属。符合本页数字只可判断其原观察范围，不自动升级成当前版本或整景通过。
- 观察前确定局部或全局事件分类。秒级判断采用实际事件与源帧开始的时间戳，不采用读回完成时刻。不能把旧记录的 +30／+59 帧按 30FPS 开发目标换算成实测秒数；首次越线未知时报告已观察上界，不编造精确时刻。稀疏样点不能证明持续保持 0.5 秒。
- 记录实际相机／GI 尺寸、源帧间隔和采集等待。640×360 结果不外推为 960×540／30FPS 的响应；采集同步停顿不直接归因产品。跨过截止时刻才取得的样点报告其实际时间，不冒充截止前已经达标。
- 名义误差落入目标且无明显结构错误，可以标明“该有限比较满足工程目标”，同时列参考不确定性。超标说明该观察配置未满足工程目标，先核对来源与物理量；不自动等同代码缺陷、启动调参、放宽目标或升级参考系统。
- 本页消除等待用户数值的决策依赖，不新增 CI、平台、场景或测试矩阵，不撤销已结束候选。需要新观测时仅补会改变修复或放行决定的一项直接证据。

## 当前可复用结果

原第6节G1的本机代表性传输验收现已按上述判据与已有依据关闭，见[逐项裁决](ProductionPlan.md#g1本机代表性传输验收裁决)。Astra Max与独立审阅确认133补齐当时缺少的当前颜色比较后，无另一具体行为阻断这一代表性关卡；不再用任意场景／全像素的泛化准确性作为前置。下述各结果仍只在其原范围成立，未执行协议、第8／9节专项和完整G3–G5继续保留，没有新增参考或改变阈值。

原红墙反射率换蓝事件现有当前122同源Runtime的有界D观察：原640×360场景，Floor相对独立蓝前史产品控制，在1.142–1.654秒形成首个均值合格保持窗口，后续观测至2.612秒未越线。该Floor控制满足事前5%／.025稳定性资格；White控制Y波动9.03%不合格，其恢复不能采用，整体状态仍为控制不足。它不是发光板事件、物理真值、全像素恢复或普通Player性能；Astra同意部分采用后结束，不补采／延长控制。[两域、控制资格及源时刻](../LocalComparison/Review/reflected-color-response-01/result.md)

已有封闭反射房间的局部点光关断，固定九点已观测到1／2秒前旧绿均值剩0.04606%／0.004056%，后续保持目标，末端实际filteredD有效。此项符合该有限域的残留判据，不代表任意房间的稳态或完整多跳算子证明；源节奏约29.30Hz也不等于普通Player性能。[同曝光图、源帧与采用边界](../LocalComparison/Review/sealed-room-decay-01/result.md)

Release93 的静止 Floor／White 平均亮度偏差为 −3.075%／−0.831%，色向 L1 为 0.007976／0.033415。原逐像素亮度 MAE 与参考均值之比分别约 14.69%／8.18%，名义上满足上面的静态目标。此判定仅覆盖原两个区域、单时点及 640×360 参考网格，不改写原 Monte Carlo 与模型边界。[原比较](../LocalComparison/Review/release93-color-frame119-01/result.md)

当前122同源Runtime现已直接复用原归档场景0–119及同一有限参考，两个固定ROI的同量filteredD也取得上述报告指标，名义满足静态目标；Floor的2个unknown继续单列。Astra同意采用并结束本线。它补上当前Runtime在该归档样点的依据，不把Final／旧IndirectOnly普通输出互相比作物理真值，也不证明全部像素相同、普通三室、960×540／Player或完整G1。[当前观察与收束](../LocalComparison/Review/archived-runtime-color119-01/result.md)

Release114 的绿转蓝旧绿在 +10／+30 帧为 1.43%／0.285%；这些点支持衰减趋势，没有秒级时间锚点，不能直接判 1／2 秒目标通过。Release109 换蓝后 +30 帧仍比首帧蓝墙路径暗约 12%，也不足以判定 2 秒后的结果。门运动四时点的已有取舍继续保留。[旧绿消退](../LocalComparison/Review/green-emission-decay-114/result.md) · [蓝墙前史](../LocalComparison/Review/blue-wall-history-01/result.md)

当前 Release122 产品在一个固定绿转蓝光路上已有 Final HDR 恢复比较：960×540、实际约 29.4Hz，相对同工作帧、较长蓝前史产品控制，区域均值首个合格窗口为 0.193958–0.708270 秒，之后观测到 2.612935 秒未再次越线。起点最差单点仍有 23% 亮度差，约 2 秒最差点约 1%；这不是全像素的精确收敛时间或物理真值。1 秒前 0.978545 秒旧绿均值为 0.265508%，2 秒前 1.970665 秒为 0.0229948%。这只补该固定域、该量与节奏下的恢复依据，原门运动和整体 G3 继续按各自范围判断。[同帧画面、完整源帧与采用边界](../LocalComparison/Review/final-state-response-01/result.md)

同一既有实际棕墙／白地板光路的全源关断另有一次发行质量观察：1 秒前 0.985461 秒旧绿均值为 0.277411%，2 秒前 1.984781 秒为 0.0252869%；末帧实际 filteredD 与掩码确认固定点有效，仍为极低非零值。响应期时域有效标签不能冒充当前 raw 新鲜或每帧 filtered 有效。126／127 原冻结文字把墙误写成白色，实际墙 MPB 为 (0.5,0.25,0.125,1)；仅采用实际配置，全白墙及高反射率条件未验证，原合同保留。数值目标没有据结果调整。[关断数值、有效性及描述偏差](../LocalComparison/Review/all-source-off-response-01/result.md)

## Astra Max 审查与下一步

Astra Max 已审查，允许作为本项目起始工程判据使用；上文已补入平均域、事件预分类、源帧时间、采集影响和稀疏样点的限制。93 静态结果只记为原区域的名义满足。

批准的下一项是一次复用 GreenDecay 的有界时间观察：同一绿转蓝事件、既有接收域与发行质量配置，补实际源帧时间，仅判断旧光消退。它不要求新蓝稳态参考，不关闭新颜色收敛，也不重开门运动。结果无论达标、超标或不足均按此次范围收束，不自动补跑。审查不代替主线程的开发与交付责任。

该观察现已完成并经 Astra Max 收束复核：实际源帧 1.000209 秒旧绿均值为切前的 0.0429214%，2.000477 秒输出 G 全零。样点低于对应残留幅度目标；严格截止时刻和普通 960×540／30FPS 响应仍未由此证明。显式请求的较快节奏、采集相邻约 0.43 秒间隔和有限精度零值均保留。[结果与边界](../LocalComparison/Review/timed-green-response-01/result.md)
