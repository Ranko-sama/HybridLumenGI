# 全局灯光变化后的旧色残留

已修复一个明确的动态响应问题：实际全局灯光记录变化后，如果当前像素已有可信测量，屏幕滤波从当前测量重建历史，不再继续混入变化前的光照。

依据是已有真实有限色墙关光图：当前采样已经可信为黑，旧屏幕历史首帧仍残留最大 RGB 0.019989，之后缓慢衰减。此前只把历史年龄限制为 2，仍留下半份经过夹取的旧值；下一帧年龄又开始累积，拖长尾部。

最小修改在 `CSTemporal` 的未知测量早退之后、历史重建之前检查现有 global reactive 标志。真实着色器配对中，已知黑首帧输出由 0.019989 改为 0，年龄为 1；已知非黑使用当前值，unknown、静态与普通局部运动输出保持原字节。两条历史入口均核对，并经另一子代理独立审查。

该标志当前覆盖方向光等全局变化。此处没有扩大点光、MPB 或运动标记的语义，也没有把未知值当黑。刷新时可能短暂增加噪声，这是不继续混入过期照明的取舍。当前估计自身携带的多跳缓存残留仍然存在，需单独由独立画面对照衡量。WARP 配对不能替代完整场景的纹理接线或默认多反弹质量验收；修改已纳入 Release74 构建。

证据：[配对结果](../LocalComparison/Review/temporal-global-light-reset-01/result-02.json)、[最小修改](../LocalComparison/Review/temporal-global-light-reset-01/candidate.patch)。首次适配器缺少 header 的编译失败保留，发生在数值执行前。
