# denoise-02 predeclared checks

The existing GPU harness will exercise the shipped kernels and composite shader in Unity DX12. No copied temporal/filter implementation is used as an oracle. The synthetic camera is identity VP/inverse VP, with same-pixel reprojection and a valid +Z plane. Radiance storage is RGBA16F, temporal moments RGBA32F; identity textures are uint4, candidate rows uint3, object rows 80 bytes. All output pixels and channels are checked for finiteness after storage, not just the center.

- Constant grayscale 255, 256, 1000, 65504 for five ping-pong frames, both CSTemporal and CSTemporalIdentity. Radiance absolute tolerance max(0.001, |value|*0.001), temporal first/second moment tolerance max(0.001, |expected|*0.000003), history length tolerance 0.001. Nonnegative variance is not required to equal zero exactly after float rounding. These tolerances are declared before executing the new harness.
- Preserve the five existing synthetic cases, now with full output finite checks. The known bright-neighbor spatial variance cap remains 65504. An unknown center has no valid history and must stay unknown.
- For both temporal kernels: unknown current retains valid old history, invalid old history clears; nonfinite old moments reject; unknown geometric normal retains single-frame current only; reset restarts; reactive caps history at 2; maxHistory=1 remains 1. Identity accepts a matching real identity row and rejects a changed previous primitive.
- The 17x17 diagnostic chain uses the unfiltered temporal history as history feedback, the same temporal moments for filter steps 1,2,4, and separate filter targets. Record history 1 through 5 with fixed noisy input and same-plane/parallel-plane/material/normal boundaries. Output changes and dark-side increments are diagnostics, not automatic acceptance or new quality thresholds. Finite output and unchanged confidence are mandatory.
- Render debug slot 3 with the actual composite shader. For valid pixels its grayscale must match variance/(1+variance) within 0.002; uniform accumulated input should be zero, noisy reset input nonzero. This proves display semantics, not history acceptance.
- Run the existing integer screen-budget oracle with the updated physical allocation inventory; check a 640x360 half-resolution identity run still fits the existing 128 MiB setting at 320x180. Expected additional moments storage is 921600 bytes, independent of identity enablement.

Stop on the first contract failure, save the failing report, and repair the minimal reproduction. Only new changes, failures, or uncovered requirements justify rerunning. No full scene matrix, long performance run or new filter tuning belongs in this package. A finite synthetic test is not physical or dynamic image acceptance.
