# 固定 Lit 裁剪发光三角的面积采样

原计划第 9 节／T2 的固定裁剪源点通过。Release258 同源工程在 Unity 6000.0.85f1／RTX 2080 Ti／DX12 下复用原双槽 Lit 网格和生产面积分布。蓝板添加一张 2×1 的线性 RGBA32 BaseMap，Point、Clamp、无 mip，两个 texel 的 alpha 为 0 和 1，裁剪阈值为 0.5。真实命中材质批在两种追踪前录制了一份贴图复制。[Release258 同源工程](../streamed-shared-mesh-326/delivery.json) · [原不透明源点对照](../native-area-sample-323/result.md)

两个固定样本都选蓝板槽 1 的三角 0。采样位置分别为 `(−0.5, −1.25, 1)` 和 `(0.5, −0.75, 1)`。两条射线垂直于三角，距离都是 0.5。分布包含的总世界面积为 20，因此独立解析预期为 `pL = 0.5² / 20 = 0.0125`。实心处采用纯余弦方向分布，蓝光贡献应为 `1 / (1 + π × 0.0125)`。

| 固定输入 | 精确软件 BVH 与 DXR 的共同结果 |
| --- | --- |
| alpha 0，透明孔 | 面积样本 PDF 0.0125000011，世界查询未命中，面积贡献为已知零 |
| alpha 1，实心 | 源 Le 为 (0, 0, 1)，采样和命中反求 PDF 均为 0.0125000011，方向权重及蓝色面积贡献均为 0.96221399 |
