# Release137 · 粗根尚未绑定时的近景细节准入

统一示例保留已启用粗根的组声明。全部近景细节完成各自的分页绑定后，即可按原距离与整组就绪条件进入 GI 准备。只有收到完整发布回执，普通 Renderer 才会整组取得提交资格。

Unity 无图形 Play 使用真实 AssetBundle 和受控到达顺序。在粗根始终未绑定的前提下，Release136 已齐备的三件细节仍被挡在准入门外。Release137 中，第三件绑定后全组取得资格，受控完整回执后全组可提交。该结果覆盖准入及整组显隐，实际冷近场画面与高速首显分别验收。[对照与适用范围](https://github.com/Ranko-sama/HybridLumenGI/blob/fe8883aacfaa9ec90327ee9fecc328abcc3ef1e6/LocalComparison/Review/cold-detail-admission-154/result.md)

普通 Win64 包从同版 Unity 工程 ZIP 的独立解压目录构建。使用 Unity 6000.0.85f1 和 URP 17.0.4，完整解压后运行 `Start-LocalRelease.cmd`。离线画册、Apache-2.0 许可证和第三方通知随附。[固定产品源码](https://github.com/Ranko-sama/HybridLumenGI/tree/fe8883aacfaa9ec90327ee9fecc328abcc3ef1e6)
