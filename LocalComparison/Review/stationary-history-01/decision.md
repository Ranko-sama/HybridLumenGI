# 静止样本的历史保留候选

候选只改变已通过原历史门槛、达到现有MaxHistory、无reactive且相机VP、实际采样位置、motion/jitter、几何与材质完全未变的样本。它保留原最近历史，跳过subpixel重建及当前raw邻域RGB裁剪；其余路径保持。没有新增参数、资源或照明追踪机制。

立项依据是既有35fddaa frame119同票据数据：Floor的filteredY / raw亮度时间矩 / 参考Y分别为0.05096342 / 0.06951409 / 0.07168874；White为0.15118381 / 0.22576375 / 0.22695730。有效域13328 / 86点，与已有颜色对照相同。输出比自己的raw亮度时间统计低26.7% / 33.0%，支持优先检查重建；不能据此单独归因temporal或spatial，moment不是物理真值。

## 执行前固定的采用判断

1. 使用已有实际temporal-body WARP宿主检查主反例、已标记变化/运动/显露及unknown控制；相关旧路径必须保持。另在同一有限执行中明确输出**未标记真实变暗**的残留，不能把它排除后称动态不变。它应沿用原配置EMA，不引入更长权重或额外历史。
2. 只有数值行为和副作用可解释，才运行一次保存V209场景0–299前缀；仅捕获119、239、240、270、299，使用原Capture API，不新增参考积分、捕获框架、哈希或性能测量。
3. frame119与已有当前基线及同一独立参考比较：原Floor/White有效域均需降低绝对均值亮度偏差和逐像素亮度MAE，色向L1不恶化，不能靠新增未知点得到改善。均值变亮本身不构成采用理由。同曝光检查不得出现明显新增亮点、斑块或边缘拖影。
4. 关灯时点同时保留普通出射图和D；239/240/270/299用于查看通知事件后的保留与变化，299可复用已有299独立参考，但不把晚帧当真值或推导精确收敛时间。旧Release78出射图只提供历史上下文，不冒充35fddaa精确A/B。若出现明确新增旧光轮廓、抹掉接收面反弹或解释不了的异常，则撤回。
5. 失败或不明确则结束，不调整门槛、权重或扩大采集来寻找收益。候选即使采用，也只关闭此有限静止重建缺口；整体动态与G1/G3仍开放。

## 已知代价

同一接收点不证明照明恒定。未被变化域标记的远处多跳变化会按原EMA较慢消退，稀疏亮采样噪声也可能保留更久。MaxHistory只是配置相关的成熟窗口，不保证任意设置都有很长冷却。此候选不取代来源更新通知或完整动态依赖传播，也不扩大运动/TAA支持结论。
