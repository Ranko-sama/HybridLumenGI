# 世界缓存递归拒绝硬失效域的旧值

Release157 的世界缓存更新会清除硬几何域内的目标旧值，但同一轮 Jacobi 更新读的仍是上一轮缓冲。旧版在标签和图卡代次一致时可以从这个旧缓冲取回本该作废的源值。修复在递归读取时按源锚点检查当前硬几何域，避免旧贡献写入另一图块的新估计。[旧版读回](baseline.json) · [修复版读回](fixed.json)

复用 D3D12 WARP 宿主，执行实际 `HLGICachedSurface`、变化域函数和缓存有效性判断。图卡寻址、连接无遮挡及两个缓冲的输入由宿主提供。双线性读取四个等权样点，左右各两点，分别复用一个锚点。旧输入为红 `(4,0,0)` 和蓝 `(0,0,2)`，标签与代次全部当前。

| 旧缓存输入条件 | Release157 的递归读取 | 修复版的递归读取 |
| --- | --- | --- |
| 红侧硬域，蓝侧在域外 | `(2,0,1)` | `(0,0,2)` |
| 相同边界，仅软照明变化 | `(2,0,1)` | `(2,0,1)` |
| 全局硬失效 | `(2,0,1)` | 无可用缓存样点 |
| 红侧在原不相交位姿的影响半径内 | `(0,0,2)` | `(0,0,2)` |

Gather 读取适配的当前绿／蓝结果，两版均返回 `(0,3,1)`。全局硬失效时沿用原缺缓存分支，未写入一份黑色缓存测量。局部仅软变化时，新增的几何标记为零，递归读取跳过区域扫描。

实际 `ChangeRegions` 宿主验证了硬域设置、重置、纯软域和同边界升级时的绑定。首次编译因旧适配器缺少已有 `DisjointSourcePose` 字段而停止，补齐该字段后通过。采用范围为读取资格和绑定，实机画面、残留时长及 GPU 成本继续验收。[绑定对照](../../../Tests/StandaloneChanges/Program.cs.txt)
