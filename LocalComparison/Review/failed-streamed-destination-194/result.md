# 活动分页绑定终止失效后的安全回收

已取得几何与材质页租约的流式表示，在 MeshRenderer 被销毁后会进入终止失败。旧逻辑仅撤销请求，仍将绑定视为可用。后续 Update 跳过这个组件，持有的页租约也无法通过原来的撤回门进入安全退休。此序列可以发生在绑定组件仍启用、仍有近景需求时。

修复将已绑定组件的终止失败纳入现有的不可用状态，停用仍存活的普通 Renderer 和旧 GI 代理，再请求原不可用退休。绑定与租约保持到既有 `ReportUnloadSafe` 入口接管。它仍按当时的绑定代次受理，并等待原完成信号再归还页。

沿用实际 C# 绑定组件、驱动和页调度器的回归入口 `Tests/Validate-ChunkStreaming.ps1 -RepresentationOnly`。用 Unity 判空替身销毁一个仍被需求的完整绑定的 Renderer。实际 Update 报出配置失效、撤出代理、撤销需求并请求原不可用退休。安全确认后，绑定卸下，未完成的两个租约仍保有 60 B 的受控驻留账。完成后，租约、驻留、包字节和活动操作归零。[定向回归](../../../Tests/StandaloneStreamedRepresentation/Program.cs.txt)

交付前限定了不可用状态的适用范围。补充的冷失败控制确认，从未绑定的成员保留 Scene 所用的作者成员声明状态，且无需请求页退休。

此项关闭 T6／G4 中终止失败后无法撤回已绑定页的路径。验证采用受控对象判空、异步 I/O 和完成信号。实际 GPU 栅栏沿用原退休路径的独立证据，普通 Player 中销毁目标后的画面及重新启用恢复继续按各自条件验收。[安全退休约定](../../../Documentation/HlodStreaming.md)
