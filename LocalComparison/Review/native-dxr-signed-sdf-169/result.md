# 实际 DXR 与 signed SDF 的最近命中

Release151 在本机 DX12 实测中，较近的 signed SDF 表面胜过真实远三角，真正更近的 DXR 三角仍保持命中。两条结果均有当前来源身份及完成标记。此项关闭 T2／G4 中这组空间条件的原生最近命中缺口。 [原始读回](result.json)

## 固定输入和结果

用 Release151 源码 `027b84c0` 的独立 Unity 工程，在 Unity 6000.0.85f1、RTX 2080 Ti 上执行一次直接查询。闭合单位立方体以普通烘焙入口生成 16³ 有符号距离场，作为无 Renderer 的 MeshFilter 代理。另一个普通 Lit 网格提供两片不重叠的真实三角。实际 Scene 发布两对象，距离场上传 4,096 体素，DXR 记录一个网格和两个三角。

两条射线从盒内沿 +X 发出。原 129 对照的出口与两个三角的距离关系保持一致，近三角移到相邻的独立射线通道。每条射线在同一次提交内分别读取真实 DXR 单独查询和产品混合查询。盒面解析距离为 0.00843331 世界单位，距离场沿用原对照的 0.00026042 容差。

| 射线 | 实际 DXR 单独命中 | 实际混合命中 |
| --- | --- | --- |
| 盒面在远三角前 | 三角 0，0.00968334 | signed SDF 盒，0.00841055 |
| 近三角在盒面前 | 三角 1，0.00426665 | 同一三角 1，0.00426665 |

四条回读均为有效且已完成的命中，两个混合结果分别匹配当前 SDF owner／revision 和 DXR owner／revision。SDF 与解析盒面差约 0.00002276 世界单位。Unity 正常退出，启动前 GPU 采样为 4%。 [原截断区间对照](../sdf-clipped-interval-146/release-notes.md) · [本机退出回执](<I:/Unity test/Comparison/MixedSigned169/native-exit.json>)

Astra Max 按该固定静态几何和 DXR 查询范围采用。普通相机画面、精确软件与 SDF 的组合、贴图和正式 GPU 预算仍按各自条件验收。
