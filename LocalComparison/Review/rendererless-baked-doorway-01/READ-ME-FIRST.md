# HybridLumenGI Release120 · Windows x64

完整解压 ZIP，双击 `Start-LocalRelease.cmd`，再单击窗口接收键盘输入。默认彩墙房间使用 960×540、半分辨率 GI、2 条射线和 4 级滤波，优先 DXR。

| 操作 | 按键 |
| --- | --- |
| 只看间接光，再次按键返回 | F5，或窗口中的同名按钮 |
| 换墙色、开关解析灯 | C、L |
| 启停门运动、启停门形变、切换网格与蒙皮 | M、空格、K |
| 移动、升降、转向 | WASD、Q/E、方向键 |
| 近景、远景、离场 | 1 或 R、2、3 |
| 进入中性两室，再切换三室 | F3，在两室按 F4 |
| 开关中央滑门 | O |
| 请求软件追踪、请求 DXR | 4、5 |
| 释放或重载分页组 | B |
| 隐藏面板、写状态日志、退出 | F1、F2、Esc |

要观察墙面反弹，可在彩墙房间对准白色地板，按 C 切换墙色，用 F5 对照间接光和最终画面。离线打开 `PictureComparison/index.html` 可查看颜色误差、换色与关灯残留、运动拖影和收敛时间的实测范围。

状态日志位于解压目录上一级的 `LocalRelease120.log`。原生插件通知和许可位于 `Documentation`。同版发布页另附可编辑 Unity 工程。
