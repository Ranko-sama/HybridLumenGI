# 两盏点灯共用绿色通道时单独关灯

沿用 248 的七网格灰墙、机位、九点、同曝光和实际源时间。固定青灯在原位置以强度 3 持续点亮。纯绿点灯从停用开始，以强度 20 点亮一个原控制阶段，随后只通过普通 Light.enabled 关闭。实际灯表在低亮、高亮、关灯首帧与末帧核对为 1→2→1→1 条。

沿用已采用的画质与时钟条件。按低亮到高亮的绿增量归一，1／2 秒前的旧绿增量不超过 5%／1%，并继续保持。2 秒前亮度、绿和蓝进入匹配低亮终态 ±10%，色向 L1 不超过 0.05，保持至少 0.5 秒。青灯单独提供的蓝光整段偏差不超过 10%，整段九点绿均值最低不得比终态低 10%。两程均须符合原控制稳定性、实际 DXR、源帧间隔与有效性门。

Release207 的基线须有合格的实际响应超标才进入修复。一趟匹配候选验证既有局部照明通道刷新能否处理纯移除事件。若记录不足或候选未通过，收束这一候选。
