# HybridLumenGI Release117 · Windows x64

将整个 ZIP 解压到新目录，双击 `Start-LocalRelease.cmd`，再单击窗口接收键盘输入。默认从彩墙房间开始，窗口 960×540，GI 半分辨率，每像素 2 条射线，4 级滤波，优先 DXR。

| 操作 | 按键 |
| --- | --- |
| 移动、升降、转向 | WASD、Q/E、方向键 |
| 近景、远景、离场 | 1 或 R、2、3 |
| 进入中性两室，再切换三室 | F3，在两室按 F4 |
| 开关中央滑门 | O |
| 请求软件追踪、请求 DXR | 4、5 |
| 换墙色、开关解析灯、启停门运动 | C、L、M |
| 启停形变、切换网格与蒙皮 | 空格、K |
| 释放或重载分页组 | B |
| 隐藏面板、写状态日志、退出 | F1、F2、Esc |

离线打开 `PictureComparison/index.html` 可查看颜色误差、换色与关灯残留、运动拖影和收敛时间。「离屏纹理与连通房间」一节另有单槽 Lit 材质切换接收阴影的实际读数，以及旋转遮板的 GPU 光路与碰撞查询对照。「三室步行路线」一节说明远景组首次出域时的可见状态。

状态日志位于解压目录上一级的 `LocalRelease117.log`。原生插件通知和许可位于 `Documentation`。同版发布页另提供可编辑 Unity 工程，解压后按工程根目录的 README 打开或重新构建。
