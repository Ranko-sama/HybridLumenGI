# 单一形变来源借用空闲工作槽

沿用真实统一示例的两骨门，将上骨固定在 15° 并用 `BakeMesh(false)` 捕获 24 顶点、12 三角。两版在同一 Unity 6000.0.85f1 无图形进程比较同一组数组的 SDF32 完整烘焙。墙钟区间从进入烘焙到距离数组返回，覆盖 BVH 构造和闭合判断。

| 固定输入 | Release241 单槽 | Release242 双槽候选 |
| --- | ---: | ---: |
| 完整烘焙中位 | 101.372 ms | 63.404 ms |
| 闭合、边界与距离数组 | 闭合，原边界 | 边界相同，32,768 个体素逐位一致 |

同对中位节省 **37.483 ms**，两侧中位相差 **37.45%**。收益超过事先规定的 33.333 ms、20% 和组内波动，最大组内极差为 10.631 ms。采用范围是该固定输入的 SDF 烘焙经过时间。端到端发布延迟、CPU 总工作量与普通 Player 的形变画质各自验收。[本机原始对照](<I:/Unity test/Comparison/DeformedBake298/result.json>)

使用实际形变组件与 SDF 核，在既有 C# 宿主的切片回调插入受控停点。取消和一侧抛错时，另一侧仍执行的期间，两槽和私有快照预留均保持，快照未发布。另一侧结束后，原任务按现有规则清理，等待的网格随后完整发布 Mesh、SDF 和图卡。同步汇合覆盖正常结束和异常结束，发布按原上传与内存预算推进。[并行操作的完成语义](https://learn.microsoft.com/en-us/dotnet/api/system.threading.tasks.parallel.invoke?view=net-7.0)
