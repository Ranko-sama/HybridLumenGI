# Release181 精确投影覆盖变化的更新范围

普通 Lit 投影板的裁剪覆盖改变时，受影响的直接光接收面可能在 GI 追踪范围以外。旧版无图卡精确材质只通知近域。Release181 使用相机成功录制的精确投影覆盖作为基线。投影覆盖改变时，按已选实时投影光的可达距离加一段 GI 追踪距离通知局部更新，并提高范围内缓存的调度优先级。方向光取配置的阴影距离，点光和聚光取灯光范围。实际采样 alpha 的已赋值 BaseMap 若发生版本变化，CPU 无法区分 RGB 和 alpha 的变化，采用较远的局部域。[实际覆盖判定](../../../Runtime/HybridLumenGIHitMaterialLayout.cs) · [变化录制入口](../../../Runtime/HybridLumenGIRendererFeature.cs)

在同一独立解压的 Release180 工程中复用有限墙观察入口，只更换两份候选 Runtime。Unity 6000.0.85f1、Direct3D12 Editor Play、实际 DXR，固定 128×64 相机。地板六张图卡，投影板零图卡，两份精确网格均提交。地板中心沿固定方向光方向到投影板冻结包围盒为 11.9989 单位，GI 追踪距离为 4，方向光阴影距离为 30，阴影强度为 1。

投影板使用普通 Lit 二值 Alpha Clip、未赋值 BaseMap、材质 alpha 0.5。第 4 帧把 Cutoff 从 0.75 改为 0.25，按实际录制来源的标量判定从裁除变为覆盖。第 5 帧只改 BaseColor 的 RGB。读取实际上传的变化缓冲和地板缓存调度优先级。

| 事件 | Release180 软域半径／地板优先级 | Release181 软域半径／地板优先级 |
| --- | ---: | ---: |
| 改变投影覆盖 | 4／0 | 34／1000 |
| 仅改变 RGB | 4／0 | 4／0 |

两版的材质记录均已知，世界缓存代次为 5，精确几何版本为 1，全局照明和几何失效标记均为 0。两次 Unity 进程正常退出。Astra Max 采用该固定无图卡来源的变化通知与调度结果。标量覆盖结论来自实际录制来源值；像素、光照残留、收敛时间、有图卡路径和其他灯型各自验收。[原有限墙观察入口](../cardless-material-157/result.md)
