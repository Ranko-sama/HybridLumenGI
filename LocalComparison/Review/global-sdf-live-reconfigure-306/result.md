# Global SDF 活动重配的缓冲退休

在同一个已启用的 Global SDF 实例上，公开 `Prepare` 接受新的裁剪图布局、距离度量和对象容量。Release246 在替换时立即释放原缓冲，已经提交的旧代也从逻辑账目消失。修复先准备完整替换，再把被替换缓冲交给关闭路径已有的统一退休流程。临时分配失败时由原状态继续持有原缓冲。[实现及使用范围](../../../Documentation/GlobalSdf.md)

复用 `Tests/Validate-GlobalSdf.ps1 -CpuOnly`，对同一实际组件先录制更新，再切换体素尺寸。旧版在首个退休保留断言失败。候选保持对象边界缓冲，旧裁剪图继续计账。完成前切回原体素尺寸并把对象容量从 4 改为 8，新的配置取得自己的缓冲并继续录制。两份旧代合计 **83,200 B**，当前代 **41,792 B**。依次触发两个完成回调后，每份旧缓冲各释放一次，当前代保持可用。回切前注入一次部分分配失败，已创建的临时缓冲被释放，现有代次及旧退休账目保留。[定向回归](../../../Tests/StandaloneGlobalSdf/Program.cs.txt)

对照使用实际托管代码和受控缓冲、命令及退休完成信号。普通 Inspector 重建 Renderer Feature 的流程有自己的整态退休入口。这里关闭的是同一实例公开重配时的所有权和逻辑账目。实体 GPU 的完成延迟和进程峰值仍按原条件验收。
