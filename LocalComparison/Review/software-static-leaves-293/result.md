# 精确软件 BVH 重建复用未移动实例

同一相机里的两张网格共有 4,096 个三角。只移动第二张网格时，新路径把世界三角读取从 **4,096 次降到 2,048 次**。更新后的顶点、叶身份、节点包围盒和逃逸链接与 Release237 全量重建逐字段一致。[实际读数](result.json)

| 同一受控序列 | Release237 读取 | 候选读取 | 布局 |
| --- | ---: | ---: | --- |
| 首次构建 | 4,096 | 4,096 | 一致 |
| 一张网格改变位姿，建树前再次准备同一姿态 | 4,096 | 2,048 | 一致 |
| 同三角数换源 | 4,096 | 4,096 | 一致 |

使用实际软件 Backend、相机准入与 BVH builder。Unity Mesh 和 GPU 缓冲由既有适配器提供。移动只推进位姿代次，后续一次属性准备没有新的矩阵变化。候选仍以旧 Layout 的几何代次识别已移动实例，并读取其当前顶点。源网格换成同样三角数的新对象后，完整属性重建使旧叶失去复用资格。

相机仅借用同一 Backend、同一完整属性布局中的冻结叶。实例位姿在该 Layout 之后变化时重新读取。各叶按相同顺序形成包围盒并参加 Release237 的全量分桶。采用范围限于这条路径省去重复顶点提取、矩阵变换和有效性验证。整树仍完整构建。真实 CPU 毫秒、GPU 时间、动态画质和 G4／G5 放行分别按原条件验收。[相机准入](../../../Runtime/HybridLumenGIRendererFeature.cs) · [BVH 构建](../../../Runtime/HybridLumenGISoftwareTriangleBvh.cs)
