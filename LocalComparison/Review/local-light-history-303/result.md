# 局部解析灯变化后的待替换屏幕历史

旧版对局部解析灯变化只缩短屏幕历史。暂时没有可信测量的像素仍以年龄 2 保留旧光，滤波和半分辨率合成可以把它借给同平面的可信像素。修正为实际灯表变化的原影响域保留独立标记。当前测量未知且旧历史通过原重投影校验时，保留其值并把年龄降至 0.5，沿用已有的待替换隔离规则。同 Bounds 的其他变化可以有更宽的影响域，灯光标记仍使用自己的半径。

Unity 6000.0.85f1、RTX 2080 Ti、DX12。以 Release244 的可编辑工程和实际着色器为基线，复用 [272 的固定同平面夹具](../pending-lighting-spatial-272/result.md)。GI 为 17×17，合成到 34×34。相同旧值在两条时域入口中预热后，模拟一次局部灯变化及同 Bounds 的更宽姿态影响，使用真实 C# 区域上传和绑定。可信黑与未知旧光相邻。基线和修正共用合成着色器。[执行入口](../../Harness/DenoiseRegressionEditor.LocalLightHistory.cs) · [实际读回](result.json)
