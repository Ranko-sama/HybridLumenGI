# 关灯时暂时采不到新光，旧颜色保留多久？

全局灯光改变时，像素可能暂时取不到可信的新测量。Release112 允许这类像素继续显示先前的颜色，同时把它标为待替换。第一次取得可信新值时，时间重建直接使用新值。此前程序只在灯光变化当帧记得这次事件。

| 先前为白色，当前像素的输入 | 旧版线性输出 | Release112 线性输出 | Release112 历史年龄 |
| --- | ---: | ---: | ---: |
| 全局灯变化，测量未知 | 1 | 1 | 0.5，待替换 |
| 下一帧仍未知 | 1 | 1 | 0.5，待替换 |
| 首次取得可信黑色 | 0.666667 | 0 | 1 |
| 再次取得可信黑色 | 0.499878 | 0 | 2 |

另一条轨迹让最近像素先获得新黑值，而相邻像素仍只有事件前的白色。下帧以 0.25 像素的偏移重投影时，旧版会混入 0.125 的旧光。Release112 保留了最近像素已经更新的黑色历史，输出为 0，年龄为 2。

这些值来自 D3D12 WARP 上实际运行的产品 `CSTemporalIdentity` 时间重建代码。控制场景是一块 2×1 像素的静止平面，RGB 三通道相同。每帧输出的颜色按半精度存储，矩按全精度传给下一帧。白色邻点为旧值提供了可通过空间夹取的支持。[逐帧原始与存储读数](result.json)

该修复覆盖方向光等触发全局照明变化的事件，作用于屏幕时间历史。未知期仍可显示旧色，首次可信估计自身也可能含有世界缓存中的多跳贡献。这次控制序列不能确定整景关灯后清空所需的帧数。局部墙面换色另有独立画面对照。[同一蓝墙的两种前史](../blue-wall-history-01/result.md)
