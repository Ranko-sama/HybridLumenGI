Windows x64 实验性统一示例。完整解压运行包后，双击 `Start-LocalRelease.cmd`。

全局灯光变化当帧若缺少可信采样，Release112 会保留可显示的旧值，直到可信测量到来时替换它。在实际时间重建代码的连续帧对照中，首个可信黑值的输出由 0.666667 降到 0，下一帧正常累计。已过期的邻点也会退出子像素历史重建。这项修复针对屏幕历史；多跳间接光的响应另有画面记录。

离线打开 `PictureComparison/index.html`，可查看颜色误差、换色与关灯残留、运动拖影和恢复时间。默认 960×540、半分辨率 GI、2 条射线、4 级滤波，优先 DXR。
