# HybridLumenGI Release105 · Windows x64

将整个 ZIP 解压到新目录，双击 `Start-LocalRelease.cmd`，单击三维窗口后即可使用键盘。默认进入原彩墙示例。

**走三室路线。** 按 F3 进入相邻两室，再按 F4。相机会到后室右侧入口，中央滑门初始全开。用 W 穿过右侧开口，向左按 A 对准中央门，再按 W 进入源室。O 可开关中央门。F4 切回原中性两室，F3 返回默认场景。导航为自由相机。

| 操作 | 按键 |
| --- | --- |
| 平移、升降、转向 | WASD、Q/E、方向键 |
| 近场、远场、离开分页范围 | 1 或 R、2、3 |
| 请求软件追踪、请求 DXR | 4、5 |
| 切换墙色、开关解析灯、启停原示例门运动 | C、L、M |
| 启停形变、切换网格与骨骼、释放／重载分页组 | 空格、K、B |
| 隐藏面板、写相机位置与状态、退出 | F1、F2、Esc |

打开 `PictureComparison/index.html` 可离线看颜色误差、换色与关灯残留、运动拖影和收敛时间。画册也包含白炉、零漫反射、离屏纹理、烘焙光照替换、门洞响应和三室的实走路线。三室视图为同一保存场景按实际 Player 机位重现的 Editor Final。

Unity 6000.0.85f1／URP 17.0.4，Windows x64、Mono、DX12、Linear。窗口 960×540，半分辨率 GI、每像素 2 条射线、4 级滤波，启动时优先 DXR。三室近远切换使用现有 192 张卡预算，原中性两室的 Far 仍有容量限制。25 ms／1 GiB 的已有结果适用于各自记录的负载。日志在解压目录上一级的 `LocalRelease105.log`，原生插件通知与许可位于 `Documentation`。产品提交 `fd1e632`。
