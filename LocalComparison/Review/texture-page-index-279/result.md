# 精确材质贴图复用按页匹配

Release228 的每次精确材质准备会为请求去重、确认在飞来源、匹配可复用物理页。各阶段反复扫描完整视图或页表。已有页的材质绑定随后再逐贴图查找租约中的全部页。正常稳定复用也会承担这些工作。

改动让一次请求准备使用同一个冻结视图索引。每个候选池按原物理槽顺序查看兼容页，整批命中时直接复用。新页仍按原请求顺序和空隙规则分配。录制时按槽位查询本租约借入的页，再验证同代次和元数据状态。

使用现有贴图池及材质批 C# 宿主执行实际源码。新增控制中，两个已录制的租约共用同一物理池，两个页的代次相同。只借入一页的租约接受自己的页，拒绝另一租约持有的第二页。原有同源等待、精度升级、来源失效、读者围栏及跨帧上传场景通过。宿主以受控录制、围栏和回读替身承接 Unity API。[租约控制](../../../Tests/StandaloneRayTexturePool/Program.cs.txt) · [运行时实现](../../../Runtime/HybridLumenGIRayTexturePool.cs)

关闭 T6／G4 的稳定贴图复用反复整表扫描路径。每个候选池的稳定匹配从逐视图扫描物理槽变为逐槽查索引，已借入句柄为直接定位。适用范围为 CPU 端查找与匹配工作量。新页分配、原生帧耗时和精确软件 Gather 的 25 ms 目标各自验收。
