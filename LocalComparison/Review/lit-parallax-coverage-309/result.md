# 普通 Lit 视差裁剪与精确材质命中

原计划 T2／第 9 节的有限修复。URP 17 的 `LitForwardPass` 在顶点计算切线空间视线并插值，片元用它计算视差偏移。精确材质路径此前也计算了这些量，但提前要求插值切线基适合应用法线贴图。覆盖判断现在依据有效的顶点视差帧。完整材质命中在有普通或细节法线贴图时仍要求有效的片元切线基。

使用 Release247 产品提交 `ebfe369ad6506a81c0fce9c2b15cf51c024565eb` 作基线，对照 D3D12 WARP 执行的实际 `HLGIHardwareEvaluateHit` 覆盖和完整材质入口。固定三角的顶点为 `(-1,0,0)`、`(1,0,0)`、`(0,1,0)`，法线均为 +Z，切线 `+X、+X、−X`，符号均为 +1。UV 为 `(0,0)`、`(1,0)`、`(0,1)`，观察点 `(0,0,2)`，重心权重 `(0.25,0.25,0.5)`。1×2 的 Point Clamp BaseMap 两行 alpha 分别为 0 和 1，裁剪阈值 0.5，视差幅度 0.04，采样 mip 0。

按安装的 Unity Core `ParallaxOffset1Step` 公式独立计算，顶点视线插值为 `(0, 0.2236068, 0.8944272)`。高度图 G=0 时原 `v=0.5` 移到 `0.4965106`，读取 alpha 0。G=1 时移到 `0.5034894`，读取 alpha 1。
