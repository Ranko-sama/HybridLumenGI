# HLOD 就绪回读限定到本次预热范围

Release226 在检查 HLOD 就绪时回读整座照明缓存，回调只读取当前预热图卡的快照。改动将单次请求的字节范围缩到所有已确认快照中的第一张与最后一张物理卡之间。回调以该首卡为起点计算局部索引。范围内只有快照中的卡可以产生就绪回执或空格证据。

| 受控 192 卡池，4×4 patch，96 B／条目 | 整池 | 当前请求 |
| --- | ---: | ---: |
| 首物理卡 | 0 | 102 |
| 连续范围 | 192 卡 | 18 卡 |
| 字节偏移 | 0 | 156,672 B |
| 回读字节 | 294,912 B（288 KiB） | 27,648 B（27 KiB） |

实际 `HybridLumenGIHlodReadback` 与 `HybridLumenGICacheScheduler` 源码由已有宿主执行，资源回调使用按记录的字节范围裁出的受控数据。预热组取得原完整回执，显式空格仍可让出后续更新名额，范围外的已发布卡无新回执。原非连续图卡、截短、过期来源与布局、四帧间隔和单一在途请求的用例均通过。[实际宿主](../../../Tests/StandaloneHlodReadback/Program.cs.txt) · [就绪条件](../../../Documentation/HlodStreaming.md#atomic-hlod-transactions)

关闭 T5／T6 的小范围就绪回读固定整池传输。表中的缩减限这组连续物理布局。首尾卡分散时，一次请求仍可覆盖整池。实际 CPU／GPU 耗时、高速冷入首显及完整预算各自验收。
