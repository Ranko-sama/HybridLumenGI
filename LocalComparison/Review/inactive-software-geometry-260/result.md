# 切回 DXR 后归还闲置软件几何

旧统一示例切回 DXR 后，仍持有 80,864 字节的精确软件三角属性和 BVH 缓冲。Release113 原固定近景 F2 记录在切换前后都报告这笔软件额度，且切换后退休队列为空。[旧切换对照](../disabled-dxr-retirement-01/result.md) · [本次提取的前后记录](result.json)

修复在当前相机成功录制 DXR 传输后撤回闲置软件几何。旧属性和 BVH 继续计账，沿用现有栅栏完成与销毁条件。重新请求软件追踪时按当前来源及预算重新准备。显式关闭精确软件也进入同一退休路径，本次实机覆盖 4／5 后端切换。

| 同一固定近景的普通 Player | Release113 软件几何计账 | Release215 软件几何计账 |
| --- | ---: | ---: |
| 初始 DXR | 0 B | 0 B |
| 切到精确软件 | 80,864 B | 80,864 B |
| 切回 DXR，已完成退休 | 80,864 B | 0 B |
| 再切精确软件 | — | 80,864 B |

全程保持同一机位、3 个可见细节成员和 20 个已发布对象。Release215 的四个端点都有前一引擎帧的实际后端录制，DXR 端点的硬件属性为 50,176 B。切回 DXR 端点的退休待办、持有和失败均为零，Player 正常退出。结果覆盖固定近景的逻辑额度归还和重入。瞬态切换延迟、进程显存及完整负载仍按原范围验收。[F2 摘录与实际帧号](result.json) · [Feature 退出入口](../../../Runtime/HybridLumenGIRendererFeature.cs)
