# HybridLumenGI Release110 · Windows x64

将整个 ZIP 解压到新目录，双击 `Start-LocalRelease.cmd`，再单击游戏窗口接收键盘输入。默认进入彩墙场景。

本版在相机从分页范围外连续靠近时，可提前请求远场聚合体的资源页。预取本身不绑定渲染器，也不会提前显示物体。实际冷入折返对照中，两个版本到最近点时都还没有完整组可提交；110 在回程 1.775 个世界单位后首次可提交全部三个细节，109 在回程 7.394 个单位后首次可提交聚合体。

| 操作 | 按键 |
| --- | --- |
| 自由移动、升降、转向 | WASD、Q/E、方向键 |
| 跳到近场、远场、分页范围外 | 1 或 R、2、3 |
| 查看中性两室及远近切换 | F3 进入，2 到远场，1 回近场 |
| 进入三室、开闭中央滑门 | 在两室按 F4，按 O 开闭滑门；再按 F4 返回两室 |
| 请求软件追踪、请求 DXR | 4、5 |
| 换墙色、开关解析灯、启停门运动 | C、L、M |
| 启停形变、切换网格与蒙皮 | 空格、K |
| 释放／重载分页组 | B |
| 隐藏面板、写入状态日志、退出 | F1、F2、Esc |

离线画册 `PictureComparison/index.html` 收录了颜色反弹、换色与关灯残留、运动拖影、恢复过程和方向光照贴图的对照。各图标有自己的采集条件。启动配置为 960×540、半分辨率 GI、2 条射线、4 级滤波，优先 DXR。状态日志位于解压目录上一级的 `LocalRelease110.log`，原生插件通知和许可位于 `Documentation`。
