# 流式细节页终止失效后保持完整 HLOD 组

独立分页组的一个细节绑定在已绑定状态失去目标 Renderer 时，仍启用的绑定会进入 `BoundDestination`，停止提交旧代理和 Renderer。旧 Scene 同时丢弃该成员的作者声明，因此在撤回原双叶发布的同一次准备中，把仍有就绪回执的幸存叶当作完整近景组重新发布。

现在 Scene 保留启用绑定中仍存活的 Proxy 与作者父链，并在候选准入时排除不可用的绑定。失败叶仍计入应有的细节集合。当前近景失效后，可用的粗根按原槽位、预热与就绪门接替。自动需求分类使用同一作者父链。已绑定页继续由原退休流程管理。

沿用 `Tests/Validate-HlodTransactions.ps1`，用实际 Scene、BVH 和 HLOD 就绪代码。绑定和回执由宿主控制，输入对应既有 194 对照观察到的活动绑定失败状态。

| 同一准备步骤 | 旧实现 | 修复后 |
| --- | --- | --- |
| 原双叶完整发布后，一叶仍声明但已不可用 | 幸存叶单独发布，GI 发布 1、BVH 节点 1、栅格可提交 1；根未预热 | 整组撤回，GI 发布 0、BVH 节点 0、栅格可提交 0；根开始预热 |
| 粗根取得匹配的几何、材质和光照回执 | 上一步已复现反例，旧版在此结束 | GI、BVH 和栅格均只提交完整粗根 |
| 作者主动停用失效绑定 | 同上 | 粗根保持到幸存叶重新预热并取得回执，随后按新的作者集合接替 |

关闭 G4 中独立分页把运行时失败当作作者删减、重新发布残缺细节组的缺口。作用范围是作者 Proxy 与父链仍可读取的活动绑定。证据覆盖实际 Scene 的提交资格，回执在受控宿主给出；冷高速首显、实际栅格覆盖、GPU 就绪时间和完整 G4 放行仍待各自验收。[定向事务回归](../../../Tests/StandaloneBvh/HlodProgram.cs.txt) · [原绑定退休证据](../failed-streamed-destination-194/result.md)
