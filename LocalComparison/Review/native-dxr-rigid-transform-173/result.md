# 实际 DXR 的刚体平移命中

Release153 的同一个 DXR 三角平移后，旧射线已知未命中，新射线命中当前位置。三角上传和应用侧场景重建计数均为 1，变换更新计数从 0 增至 1。两次提交各录制一个 RTAS 构建命令，先完成旧姿态读回，再移动对象。[原始读回](result.json)

独立解压产品源码 `8c71e70f202a6962310b9775fccf4edcea04438d` 的可编辑工程。在 Unity 6000.0.85f1、RTX 2080 Ti、DX12 上，实际 Scene 发布一个普通 Lit MeshRenderer。原三角的三个局部顶点为 `(1.25, −0.5, −0.25)`、`(1.25, −0.5, 0.25)`、`(1.25, 0.5, 0)`，材质为无贴图的普通不透明 Lit，保留背面剔除。只把同一对象平移 `(0.5, 0, 1)`，沿用 `Prepare`、`RecordBuild` 和 `HLGIHardwareTraceQuery`。Unity 正常退出，启动前 GPU 采样为 1%、1%、3%、2%。[退出回执](<I:/Unity test/Comparison/RigidDxr173/native-exit.json>) · [Unity 日志](<I:/Unity test/Logs/RigidDxr173.log>)

| 固定射线，方向均为 +X | 初始姿态 | 平移后 |
| --- | --- | --- |
| 原点 `(0, 0, 0)` | 距离 1.25，位置 `(1.25, 0, 0)` | 已知未命中 |

两个命中的 slot、stableId、instance 和 primitive 分别为 0、1、0、0。几何代保持为 3，命中 owner revision 从 3 更新为 4，与各次实际来源一致。两个未命中均读回查询的空结果和 3 单位距离上限。Astra Max 按这组已顺序完成的刚体输入采用。驱动内部构建算法、在飞更新、顶点形变、相机画面及成本仍按各自条件验收。
