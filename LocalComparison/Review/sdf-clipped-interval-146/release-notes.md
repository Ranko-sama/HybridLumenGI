# Release129 · 混合追踪保留更近的 SDF 表面

混合追踪先用精确三角的命中距离限制 SDF 搜索。原来的体素细化步可能跨过这个边界，漏掉末段内的闭合网格表面，进而使用后方三角的材质。现在会在既有步数内检查被截断的终点。尚未检查的区间继续报告未完成，避免当成确定空区。

在 D3D12 软件适配器 WARP 上，用同一组输入执行实际 SDF 追踪和混合最近命中选择。输入是 16³ 闭合单位盒的解析体素与受控的已提交精确命中。沿面中央从盒内出射，解析出口为 0.00843333 世界单位。Release128 选中 0.00968333 处的后方三角，修复后返回 0.00841055 处的同一盒体 SDF。更近的精确命中、无截断的盒体命中和完整空区间保持原结果。另一个合法 8 步输入在耗尽后保留未完成状态，未赋予伪交点和来源身份。[输入与实际读回](result.json)

本项覆盖混合最近命中与查询完成性。原生 DXR 查询、最终颜色画面及其他 SDF 分辨率保留各自验收范围。普通 Windows x64 包从同版 Unity 工程 ZIP 的独立解压目录构建，复用 Release128 的可用着色器缓存。使用 Unity 6000.0.85f1 和 URP 17.0.4，完整解压后运行 `Start-LocalRelease.cmd`。离线画册、Apache-2.0 许可证和第三方通知随附。[固定产品源码](https://github.com/Ranko-sama/HybridLumenGI/blob/4a88cc678afabe224cfc021ff73666222691854e/Runtime/Resources/HybridLumenGI/HybridLumenGISdfTrace.hlsl)
