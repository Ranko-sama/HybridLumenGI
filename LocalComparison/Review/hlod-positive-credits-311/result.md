# 正积分不足时保留完整 HLOD 接替

原计划 T5／T6／G4 的热态接替修复。旧版在共享三角与实例积分均为正时允许 Scene 先发布，再由实际录制检查完整工作量。剩余积分不足时，发布后的粗根会随软件回退失去原照明代次。

本次复用现有 281 的粗根、两个精确细节及独立精确物体 D。粗根有一张有效图卡，1,058 个三角超过精确上限 1,024。独立的第一台 Base 相机用三个双三角网格消耗预算，其物体在主相机驻留域外。两侧均使用 Unity 6000.0.85f1、DX12 Editor 和 128×64 显式相机提交。配置允许每帧两次构建，三角补充与突发容量均为 7。基线为 Release248 产品提交 `eff492f54896abc1ef5dc33d558295203a342e08`。[原观察入口](../hlod-exact-departure-281/result.md)
