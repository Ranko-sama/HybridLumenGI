# Release123 · 两室关门后的暖光恢复

本版修复了两室示例关门后，世界缓存继续递归使用关门前暖光的问题。系统用同源网格范围识别不相交的姿态，保留等待更新的照明用于显示。受影响的旧值暂停参与递归，取得有效估计后替换。

在原两室 960×540 DXR 观察中，Release122 在关门约两秒后仍剩开闭亮度差的 10.33%。修复后，1 秒和 2 秒前最后源的残留分别为 2.637% 和 0.214%，并保持在各自目标内。离线画册有同曝光画面和固定地板区域的逐源结果。

完整解压 Windows x64 附件，双击 `Start-LocalRelease.cmd`。可编辑工程包含同版源码、三室统一场景、作者资产与分页。工程使用 Unity 6000.0.85f1 和 URP 17.0.4。原创内容采用 Apache-2.0，第三方许可和通知随附。

关门恢复结果限于原固定两室事件和地板域。统一示例的同源普通构建用于交付整合，生产验收仍按原计划的支持范围推进。
