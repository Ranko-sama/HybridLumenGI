# 普通 Lit 图卡与精确命中的贴图法线

图卡原先在片元阶段将插值切线重新正交化，和 URP Lit 及精确材质路径使用的插值帧不同。同一表面的图卡着色法线因而可能低于世界缓存的 0.85 法线匹配条件。修复后，图卡用原插值切线、法线及其带手性的叉积转换贴图法线，再归一化结果。切线无效时仍回退到插值顶点法线。视差继续沿用原卡视线和 UV 计算。[图卡着色器](../../../Runtime/Resources/HybridLumenGI/HybridLumenGICardCapture.shader) · [缓存读取条件](../../../Runtime/Resources/HybridLumenGI/HybridLumenGITransport.hlsl)

使用 Unity 6000.0.85f1、URP 17.0.4、RTX 2080 Ti 和 DX12。普通不透明 Lit 的一个三角在单位变换下使用同手性、各自正交的顶点帧。材质取恒定切线空间法线 `(0.96, 0, 0.28)`，法线缩放为 1。真实卡捕获、源三角绑定和图集读取在同一个 Editor 进程中执行。旧图卡使用归档的 Release245 着色器。精确参考执行软件和 DXR 共用的材质帧计算，另由 CPU 按实际纹素位置和顶点插值独立计算 Lit 法线。[原始 GPU 读数](result.json)

| 同一图集纹素 `(24, 17)` | Release245 | 修复后 |
| --- | ---: | ---: |
| 图卡着色法线与精确材质参考的点积 | 0.59277004 | 0.99999994 |
| 精确参考与独立 Lit 公式的点积 | 1.0 | 1.0 |

两版回读的表面位置均为 `(0.497412, 0.245807, 0)`，几何法线一致。此对照关闭该有效 Lit 输入造成的法线匹配失败。测量覆盖真实图卡和精确法线计算，整条追踪的可见性、反弹输出、视差变体和其他表面输入各自验收。
