# 精确软件 BVH 与有符号 SDF 的最近命中

Release167 的实际精确软件路径在原固定空间关系下通过。较近的有符号 SDF 盒面胜过后方的软件三角，另一条射线保留位于盒面之前的原软件三角。两条混合结果都返回了当前来源身份和有效命中，查询均已完成。此项关闭 T2／G4 的这组精确软件与 SDF 混合查询缺口。[实际读回](result.json)

观察使用公开 Release167 工程包的 Runtime `df3f6276`，在 Unity 6000.0.85f1、DX12 Editor、RTX 2080 Ti 上执行。沿用 [Release151 的盒体和两条射线](../native-dxr-signed-sdf-169/result.md)。普通烘焙生成一个 16³ 有符号距离场，Scene 发布该对象和一个普通 Lit 网格。精确软件属性准备报告一个网格、两片三角和一个回退 owner，生产软件 BVH 构建器生成三个节点和两个叶子。同一命令内读回仅软件三角与含 SDF 的混合查询。

| 盒面在远三角前 | 三角 0，0.00968334 世界单位 | SDF 盒，0.00841055 世界单位 |
