# 全局灯光变化后，旧光与可信空间采样分开

全局灯光变化后，暂时没有可信新测量的像素可以显示旧值。时域重建把这类历史的年龄设为 0.5。Release222 已在时域阻止可信像素借入这个旧值，但后续 `CSFilter` 和半分辨率合成仍会混入它。修复让待替换像素通过滤波时保留自己的原值，可信中心跳过待替换邻点。全尺寸合成仍检查原几何和权重，只有可信支撑不足时才使用合格的待替换样点。

| --- | --- | --- |

| 全尺寸交界，单独对未滤波历史合成 | 0.00502068 | 0，有效输出 |
| 同一交界，四轮滤波后再合成 | 0.00436964 | 0，有效输出 |

Unity 6000.0.85f1、RTX 2080 Ti、DX12。使用已交付 Release222 工程 `50ec5bf817b5e1d9ab4c7f13d2d35abb12637d1d` 的独立解压目录和现有 `DenoiseRegressionEditor`。固定同平面上用 `CSTemporalIdentity` 写出一侧可信黑、另一侧因未知而暂留的旧光。可信年龄为 1，旧值约 0.02000427、待替换年龄 0.5。GI 17×17，全尺寸 34×34，原四轮滤波。表中为灰度输入的线性单通道值，合成行为以实际间接光调试 pass 读取。两项合成的有效标记均为 1。旧版初次读回只保留合成 RGB，结果 JSON 中对应的 `-1` 表示未记录。[实际夹具](../../Harness/DenoiseRegressionEditor.PendingLighting.cs) · [逐项读数](result.json)

首次导入在旧夹具无关的场景审计入口处编译失败，着色器未执行。仅在隔离工程去掉该入口后取得 Release222 和首候选的实际读数。首候选仍对待替换中心执行同类滤波，旧值经过四轮偏移两个半精度步长，超过事前的 0.00002 容差，按失败保留。最终候选直接保留待替换中心，实际复核只运行候选并复用已取得的旧版读数。[旧全局历史策略](../deferred-global-light-reset-01/result.md) · [本机首次导入](<I:/Unity test/Logs/PendingLightingSpatial272.log>) · [首候选](<I:/Unity test/Logs/PendingLightingSpatial272Qualified.log>) · [最终运行](<I:/Unity test/Logs/PendingLightingSpatial272Final.log>)
