# 半分辨率 GI 合成的遮挡显露边缘

原计划目标 2／G3。Release260 最终合成对异层样点降权后仍参与归一，前层的间接光因此可以进入刚显露的后层像素。修复在归一前排除超出原世界空间平面容差的已知几何样点。同层样点继续使用原空间权重。缺少可信同层样点时，合成保留原生光照。

在 Unity 6000.0.85f1、RTX 2080 Ti、DX12 上，以同一组受控输入运行 Release260 与候选的实际 `Add indirect diffuse` pass。全分辨率为 4×2，GI 为 2×1。两层平行，相距 3 cm，原容差为 1.5 cm。全像素 x=2 表示显露后的后层边界，恰好位于前层 x=1 和后层 x=3 两个 GI 样点之间。前层间接光为纯绿 `0.02`。后层分别输入有置信度的黑色和缺失值。接收面漫反射与雾透射均为 1，目标预先含每通道 `0.0625` 的原生漫反射。表中是替换模式的最终线性 RGB 读回。

| 位置及输入 | Release260 | 修复后 |
| --- | --- | --- |
| 前层样点 | `(0, 0.02, 0)` | `(0, 0.02, 0)` |
| 后层边缘，同层可信黑 | `(0, 0.00238543, 0)` | `(0, 0, 0)` |
| 后层边缘，同层缺失 | `(0, 0.02, 0)` | `(0.0625, 0.0625, 0.0625)` |

按旧版两点权重独立估计，后层有可信黑时的漏绿约为 `0.02 / (1 + exp(3 / 1.5)) = 0.00238406`，与实际读数相差约 `0.00000137`。候选在有可信黑时实际扣除了原生漫反射，在无可信支持时保留了它。

采用范围是固定双层边缘的最终合成。曲面和较粗采样在平面容差外会减少可用样点，届时沿用同一原生回退。此对照使用固定帧的合成输入，整景运动拖影、收敛时间和性能仍按原 G3／G5 条件验收。[GPU 读回](result.json)
