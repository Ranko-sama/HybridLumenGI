# HybridLumenGI Release106 · Windows x64

将整个 ZIP 解压到新目录，双击 `Start-LocalRelease.cmd`，单击三维窗口使其接收键盘输入。默认进入原彩墙场景。

**查看中性两室的远近切换。** 按 **F3** 打开两室，按 **2** 到远场，再按 **1** 回近场；无需先按 F4。按 **F2** 将当前机位、所请求和可用的表示写入日志。在本次普通 Player 中，近场为三个细节成员，远场为一个聚合体，返回后恢复三个细节。

**步行穿过三室。** 在两室中按 **F4** 进入后室，W 前进穿过右侧开口，A 向左对准中央门洞，再按 W 进入源室。O 开闭中央滑门。F4 恢复中性两室，F3 关闭房间布局。

| 操作 | 按键 |
| --- | --- |
| 平移、升降、转向 | WASD、Q/E、方向键 |
| 近场、远场、离开分页范围 | 1 或 R、2、3 |
| 请求软件追踪、请求 DXR | 4、5 |
| 红墙换色、开关解析灯、启停原示例门运动 | C、L、M |
| 启停形变、切换网格与骨骼、释放／重载分页组 | 空格、K、B |
| 隐藏面板、写入日志、退出 | F1、F2、Esc |

离线打开 `PictureComparison/index.html` 可查看按采集版本标注的颜色误差、换色与关灯残留、运动拖影及恢复过程。三室路线图使用 Release105 普通 Player 的机位记录，配图来自同一保存场景的 Editor Final。Release106 新增的是中性两室的实际远近发布读数。

Unity 6000.0.85f1／URP 17.0.4，Windows x64、Mono、DX12、Linear。窗口 960×540，半分辨率 GI、每像素 2 条射线、4 级空间滤波，启动时优先 DXR。日志位于解压目录上一级的 `LocalRelease106.log`，原生插件通知和许可位于 `Documentation`。产品提交 `7a76bfa`。
