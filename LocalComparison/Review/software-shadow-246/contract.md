# 精确软件阴影的确定遮挡提前结束

当前精确软件预算记录的 Transport 是主要 GPU 成本。普通 `TraceShadow` 只消费已知性和遮挡两个结果，仍等待最近三角。候选只在此布尔查询且实际精确几何覆盖所有已发布对象时，允许区间内经现有层、Cull、几何和材质覆盖门确认的任一遮挡提前结束。只有未知候选或遍历未完成时仍报告不确定。最近命中、面积可见性、混合回退和 DXR 保持原路径。

复用实际软件 GPU 查询入口核对已证实心、完整无遮挡、仅有未知及未知前面存在另一已证实心的判定，最近身份独立保留。原 231 的近景普通 Player、同一保存场景、同一质量、同一 512 源帧计时与显存窗口，分别由 Release205 与只覆盖候选着色器的同源工程构建。要求 GI 合计 p95 至少降低 15%，p99 降低，合计中位降低量超过两窗各自的连续分块中位极差。25 ms 和 1 GiB 的原预算门单列。语义、输入资格或收益不足时撤回候选。
