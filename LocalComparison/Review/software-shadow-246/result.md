# 精确软件阴影提前结束候选未达到收益门槛

Release205 的固定近景使用精确软件追踪时，GI 合计 p95 为 **47.200 ms**。候选让完整精确覆盖下的布尔阴影查询在确认区间内的实心遮挡后提前结束。配对窗口的 p95 为 **45.658 ms**，下降 **3.27%**，低于预定的 15% 保留门槛。两份候选着色器已撤回。Release205 继续使用既有路径。[事前条件](contract.md) · [配对判定](decision.json)

| 960×540 固定近景 | Release205 | 撤回候选 |
| --- | ---: | ---: |
| GI 三段逐源合计中位 | 46.173 ms | 44.756 ms |
| GI 三段逐源合计 p95 | 47.200 ms | 45.658 ms |
| GI 三段逐源合计 p99 | 47.818 ms | 46.332 ms |
| Transport p95 | 47.003 ms | 45.465 ms |
| 同窗进程 local 采样峰值 | 550.699 MiB | 550.574 MiB |

两窗各有 512 个连续源帧。固定机位、20 个实际精确网格、3 个完整近景成员，半分辨率 GI、2 射线和 4 级滤波。Unity 6000.0.85f1、RTX 2080 Ti、D3D12 普通 Win64 Player，反馈关闭。两侧分别从 Release205 同一可编辑工程解压构建，复用原测量入口。其范围文字仍带有历史 Release195 标签，实际产品来源由本次构建和退出记录确定。中位收益超过两窗内部的分块极差，幅度仍未达到采用门槛。目标 25 ms 和 1 GiB 分别比较，两个窗口都满足有限 local 采样预算，GI 时间仍超标。[Release205 窗口](baseline.json) · [候选窗口](fixed.json)

候选的实际软件 GPU 判定使用两张固定 Lit 板。完整且无遮挡的短区间返回已知畅通，材质缺失的近板单独出现时保留未知。同一区间还有已确认的远板时，布尔查询可以确认遮挡，独立最近查询仍报告距离 1 的近板和未知标记。实际上传的 BVH 数量与缓冲不符时，布尔查询保留未知。测试仅核对实际软件查询核心和最近身份。首次验证入口把数组长度写成 `Count`，Unity 在 GPU 判定前拒绝编译，改用 `Length` 后在同一隔离工程完成了有效读回。[GPU 判定记录](query.json)

本轮明确了当前软件固定近景的时间缺口和这一候选在该机位的实际收益。普通 Player 的动态画质、实际 Present、冷入首显和整体生产预算仍按原计划验收。
