Frozen decision contract: reactive unknown retention
Prepared before candidate product edit or execution. One finite paired batch.

Common fixed conditions
1x1 full/GI image; valid +Z shading/geometric normals; depth .5; matching .5
diffuse material; static identity transform; exact center previous UV .5/.5;
no motion; history valid; max history 32; current weight .08; normal threshold
.9; depth threshold .015. The fixed surface qualifies all product acceptance
gates. Geometry decoding/world projection are explicit fixture dependencies,
not a claimed test of their production implementation. Input/history RGB use
an explicit binary16 round-trip; moments retain float32.
Initial history RGBA=(1,1,1,1), moments=(1,1,32,0), except stated controls.
Unknown input RGBA=(0,0,0,-1); known recovery=(1.03125,1.03125,1.03125,1).
The .03125 difference remains inside the existing constant-current +/- .04
history-clipping interval; clipping must not explain the measured difference.

Exactly six rows, each executed against baseline and candidate with both actual
CSTemporal/CSTemporalIdentity variants. Event and next recovery are dependent
calls to the extracted actual body; recovered history comes from event output.
No additional parameter/seed/scene matrix is authorized by this contract.

1. reactive-unknown: event current unknown, reactive=1; recovery reactive=0.
   Baseline event length 32, candidate event length 2. All other event components
   agree bit-for-bit with baseline and the declared initial state. Recovery
   baseline length 32, alpha .08; candidate length 3, alpha 1/3. Expected RGB,
   first moment: (1-alpha)*1+alpha*1.03125. Second moment:
   (1-alpha)*1+alpha*(1.03125^2). Confidence 1; spatial variance 0 (rounding bound).
2. nonreactive-unknown: event current unknown, reactive=0. Exact paired event and
   recovery outputs; event length32, recovery length32; no changed retention.
3. invalid-old: event current unknown/reactive=1, old history confidence0.
   Event output and moments all zero; recovery must be a new current estimate,
   length1 and confidence1; no manufactured measured black during the event.
4. short-old: event current unknown/reactive=1, initial length1.
   Event length stays1, recovery length2; exact paired behavior.
5. known-reactive: event current=(1,1,1,1), reactive=1.
   Event length2, recovery length3; exact paired behavior (existing cap path).
6. hard-rejected: event current unknown/reactive=1/globalGeometryChange=1.
   Event output and moments all zero; next frame clears hard/reactive signals,
   recovery length1; exact paired behavior and no resurrection.

Bounds and decisions
- Event retained RGBA and moments.x/y/w must be bit-identical old/candidate.
  Expected initial 1/0 components, length/confidence and zero-invalid values exact.
- Primary recovery radiance max absolute error <= .0009 against the declared
  analytic values (allowing half rounding). Moments.x/y abs error <= .000002;
  spatial variance abs <= .000002; length/confidence exact. All values finite.
- Control rows' complete 16 output float components must be bit-identical
  baseline/candidate, in addition to the independent stated expected values.
- The primary candidate recovery must differ from baseline by > .004 in RGB
  and match length3, so a no-op, continued long history or hard reset cannot pass.
- Preserve the first failure and stop; no changed inputs, widened tolerance,
  repeated seed, candidate selection or extra test matrix to obtain a pass.
- A compile/adapter/host failure is test infrastructure evidence, not a product
  result. Preserve it; explain and seek the root/Pro decision before executing
  a repaired run. No automatic Unity fallback.
- This batch does not directly execute the defensive nonfinite-neighborhood
  branch with real RGBA16F inputs. Source checks require the same cap after both
  actual retention calls; no synthetic extreme-HDR texture claim is permitted.

Source identity
frozen-manifest.json freezes old Kernels and unchanged actual helpers, unchanged
existing C++ host/CMake and offline process wrapper. The runner must require the
candidate to equal the frozen Kernels text except for the exact two cap lines.
Both extracted variants, adapter, oracle, command logs, DXIL/listing, host,
binary inputs/readbacks and validation report are retained. The actual host is
reused unchanged. No Runtime or shared harness file is edited by the runner.
