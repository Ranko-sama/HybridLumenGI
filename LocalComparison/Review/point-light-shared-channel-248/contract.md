# 双点光共用通道时的调暗恢复

沿用 243 的七网格封闭灰墙、固定机位和九点、同一保存场景、960×540／半分辨率 GI、两射线四级滤波、源时间、实际 DXR。主灯仍为纯绿点灯，强度 2→20→2。另一位置的稳灯从纯蓝改成青色，强度始终为 3，提供共享的绿色通道及单独的蓝色对照。两灯实际入选并核对低亮、高亮、首降和末端 GPU 灯表。环境、发光、红色源均为零。

沿用 243 的稳定性、样点有效性和原时限。高低控制极差不超过各通道均值的 5%，归一色向 L1 不超过 0.025。低亮绿极差不超过高低差的 0.5%。高、低控制的蓝均值差以及响应全程相对低亮控制的蓝偏差均在 ±10% 内。

以高低绿差归一，1／2 秒前旧绿增量不超过 5%／1%，并满足原保持要求。2 秒前亮度、绿和蓝进入低亮控制 ±10%，色向 L1 不超过 0.05，保持至少 0.5 秒。继续使用原时域存储、末端滤波及实际灯表的资格。

先运行一次无产品覆盖的 Release206。控制无效或两期限通过时收束。若控制合格且实际恢复失败，针对同一输入修复并运行一次匹配对照。沿用低亮 ±10% 的幅度，在整段响应中额外确认九点绿均值没有低于终态 10%，避免把过暗当作残亮消退。单独的蓝通道监测稳灯是否受到牵连。
