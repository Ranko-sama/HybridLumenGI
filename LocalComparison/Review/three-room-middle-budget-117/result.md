# Release117 三室中室的本机预算

在 F4 中室可以同时看见中央门和后方表面的固定机位，GI 三段合计 **p95 为 16.170 ms，p99 为 16.729 ms**。同一窗口进程 local 显存采样峰值为 **566.191 MiB**。两项分别满足用户设定的 p95 ≤25 ms 和 local ≤1 GiB。

| 固定窗口 | 实测 |
| --- | ---: |
| 逐源帧 GI 合计中位数 | 14.938 ms |
| 逐源帧 GI 合计 p95 / p99 | 16.170 / 16.729 ms |
| 逐源帧 GI 合计最大值 | 16.870 ms |
| 进程 local / nonlocal 显存采样峰值 | 566.191 / 287.438 MiB |

**场景与负载。** 同版普通 Win64 Release/None 测量构建使用实际三室工程，调用普通 F3、F4 对应的布局操作。相机停在已有步行记录的中室机位 (0.36220, 1.5, −5.98923)，中央滑门全开，五盏灯开启。测量时完整近景三个细节成员可提交，起止均为 168 张就绪卡。采用 RTX 2080 Ti、D3D12、960×540、480×270 GI、2 条射线、4 级滤波及实际 DXR。测量构建启用原生计时和 DXGI 进程显存采样，预算反馈关闭。[原步行机位](../three-room-passage-01/views.json) · [运行条件与同窗显存记录](window.json)

**口径。** 对源帧 159–670 的每一帧，先将原生 ReceiverCapture、Transport、Composite 三段相加，再对 512 个和取分位数。local 与 nonlocal 的采样均覆盖相同源帧。此项回答稳定三室中室的成本。入场加载、运动最坏负载、整应用 GPU 时间、显示/Present 帧率及瞬时显存峰值仍各有独立口径。[来源帧、区间统计与边界](result.json) · [原始已完成计时票据](completions.jsonl)
