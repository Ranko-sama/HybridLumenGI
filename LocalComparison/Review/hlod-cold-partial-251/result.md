# 独立分页组在首片细节到达时发布已就绪粗根

两片声明叶可以装进 32 个槽。相机留在近场，粗根先绑定并取得完整回执，随后首片叶绑定，另一片叶继续等待。旧版清空组目标，撤回粗根及其回执。修复让尚无有效发布的组在细节绑定齐全前继续以已绑定粗根为目标。粗根仍通过原几何、材质和照明门。

| 受控到达顺序 | Release208 | 修复版 |
| --- | --- | --- |
| 粗根回执齐全，首片叶绑定 | 发布数 0，预热数 0 | 粗根在原槽发布，独占场景 BVH，容量阻塞数 0 |
| 第二片叶绑定，只有首片叶的完整回执到达 | 首行已复现缺口 | 两片叶一起预热，粗根继续发布 |
| 第二片叶的完整回执到达 | 首行已复现缺口 | 两片叶一起发布，退出粗根 |

对照使用同一 `Scene.Prepare`、BVH 和就绪表源码入口，绑定顺序及完成回执由现有 C# 夹具控制。适用范围为独立分页组有可用粗根、近场细节分批绑定时的发布决策。原生页到达时延、实际首显画面及统一示例高速穿越仍待验收。 [修复入口](../../../Runtime/HybridLumenGIScene.cs) · [夹具](../../../Tests/StandaloneBvh/HlodProgram.cs.txt)
