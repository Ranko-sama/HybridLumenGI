# 固定 Lit 发光三角的面积采样与可见性

原计划第 9 节／T2 的一个代表子项通过。Release256 同源 Unity 工程复用 320 的普通不透明双槽 Lit 网格。生产 C# 面积分布纳入两块板共四个三角形，随后由同一批次的实际软件 BVH 和 DXR 执行生产采样、最近命中、材质求值和 MIS。Unity 6000.0.85f1 在 RTX 2080 Ti／DX12 上正常退出。[源工程与版本](../screen-history-reconfigure-322/delivery.json) · [前次背面发光对照](../backface-emission-320/result.md)

两个固定采样都选择蓝板槽 1 的三角 0，在其内部点 `(0, −0.5, 1)`。第一条射线从两板之间出发，第二条射线从红板前方出发。总世界面积为 20，所选三角的面积为 8，方向与表面垂直，因而独立解析预期为 `pL = 距离² / 20`。纯余弦方向采样在该方向的 `pB = 1/π`，无遮挡时方向权重和蓝色面积贡献均为 `1 / (1 + π × 0.0125)`。遮挡时预期为已知零。

| 固定输入 | 软件 BVH 和 DXR 的相同读回 |
| --- | --- |
| 距蓝板 0.5，无遮挡 | 源 Le = (0, 0, 1)，采样和命中反求 PDF 均为 0.0125000011，方向权重和蓝色面积贡献均为 0.96221399 |
| 距蓝板 2，红板在距离 1 | 源采样 PDF 为 0.200000018，实际最近命中是红板，蓝色面积贡献为已知零 |

采用范围限这个不透明静态输入、固定源点、关闭引导的余弦分支与实际精确可见性。贴图及裁剪端点、屏幕与世界最近命中竞争、整景均值和方差各自验收。观察器从 Editor 独立调用生产 Compute 函数，Runtime 沿用 Release256。[原始读回](result.json) · [本机执行回执](<I:/Unity test/Comparison/NativeAreaSample323/native-exit.json>)
