# 精确软件 Gather 的延后材质求值候选

候选将完整世界材质求值延至确定需要它的方向或面积样本。世界最近覆盖仍给屏幕查询限距，面积光遇到已确认的独立近遮挡时保留零贡献。同一 Release208 固定近景的配对成本未达到采用门槛，四份 HLSL 改动已撤回。[事前条件](contract.md) · [候选源码](candidate.patch)

| 960×540 固定近景 | Release208 | 撤回候选 |
| --- | ---: | ---: |
| GI 三段逐源合计中位 | 45.909 ms | 46.890 ms |
| GI 三段逐源合计 p95 | **46.868 ms** | 47.804 ms |
| GI 三段逐源合计 p99 | 47.240 ms | 48.181 ms |
| Transport p95 | 46.676 ms | 47.613 ms |
| 同窗进程 local 采样峰值 | 551.699 MiB | 546.387 MiB |

采用条件要求 p95 至少降低 15%、中位收益超过块中位极差且 p99 降低。两窗的最大块中位极差为 3.482 ms，观测中位差 0.980 ms。两侧尾部和块波动支持撤回决定，精确的性能差异仍有不确定性。[基线原读数](baseline.json) · [候选原读数](fixed.json) · [采用判定](decision.json)

两侧从同一个 Release208 可编辑工程独立解压。使用 Unity 6000.0.85f1、RTX 2080 Ti、D3D12 普通 Win64 Player、同一固定近景、半分辨率 GI、2 射线和 4 级滤波，反馈关闭。实际精确软件接管 20 个网格，近景组 3 件完整可见。计时采用每侧 512 个配对源帧。观察器范围文字沿用历史版本号，实际源码和场景以本次构建及运行回执为准。

采用判断以这对成本窗口为准。独立语义核对止于源码，确认候选在代码上仍保留最近覆盖、原屏幕比较和远段足迹。两窗有限 local 显存低于 1 GiB，软件 GI 时间仍高于 25 ms。应用 Present、动态画质、高速冷入与完整 G4／G5 分别按原计划验收。
