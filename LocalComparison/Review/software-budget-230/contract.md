# Release195 精确软件预算窗口

G0 的正式本机基线使用 DXR。此次补齐同一 Windows 设备上当前精确软件回退的实际成本边界，采用同一开发预算作比较。Release83 软件结果与当前版本、质量和工程分别记录。

使用公开 Release195 的同源工程、保存的统一示例、普通 Win64 Release／None 和默认固定近景。原相机、灯光、几何、配额、960×540 backbuffer、半分辨率 GI、2 射线及 4 级滤波保持原配置。通过示例的既有入口选软件追踪，启用原生只测量和同窗进程显存采样，关闭反馈和交互。测量构建仅接入既有 Release83 观察器，关闭测量 UI。实际录制后端须连续为精确软件，场景与页在预热后持续就绪。

沿用 512 个连续源帧和原完成票据配对。逐源求和 ReceiverCapture、Transport、Composite，再算 p95／p99。进程 local 和 nonlocal 单列有限采样峰值，样本窗口与 GPU 源帧一致。预算比较为合计 p95≤25 ms、local≤1 GiB。相机回调频率单列。一次完整窗口按事实采用，资格不足保留缺项。此观察属于固定软件后端成本，普通 Present、冷入、动态负载及整体 G4／G5 各按原条件验收。
