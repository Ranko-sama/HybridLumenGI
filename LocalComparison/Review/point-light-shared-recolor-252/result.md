# 固定双点灯中一盏从青色换成蓝色

两盏点灯保持开启时，强度 20 的青灯换成蓝色。另一盏青灯保持强度 3。实际灯表从 `(0,20,20) + (0,3,3)` 变为 `(0,0,20) + (0,3,3)`。Release208 跳过了归零的绿色，留下的青灯继续供应绿色，旧解析绿色也随缓存反弹。修复让确定为零的当前通道进入已有的点灯比例比较，使变化比例不同的绿色按原规则刷新。[事前范围和判据](contract.md)

| 同曝光线性间接光 | Release208 | 修复版 |
| --- | ---: | ---: |
| 约 1 秒的旧绿增量，占换色前增量 | 12.72% | −0.29% |
| 约 2 秒的旧绿增量，占换色前增量 | 6.33% | −0.19% |
| 约 2 秒的绿通道偏差，相对蓝色终态 | +43.96% | −1.35% |
| 约 2 秒的色向 L1 偏差 | 0.07969 | 0.00456 |
| 首个达到亮度、绿、蓝和色向门槛的 0.5 秒保持区间 | 本窗未达到 | 0.258–0.768 秒 |
| 响应全窗绿色相对终态最低偏差 | +29.75% | −2.49% |
| 响应全窗蓝色相对终态最大绝对偏差 | 1.29% | 1.17% |

两侧使用相同七网格灰墙、固定正交机位和九个接收点。Unity 6000.0.85f1，RTX 2080 Ti，Direct3D12，Editor Play 实际 DXR。输出为 960×540 的 IndirectOnly，半分辨率 GI、2 条射线、4 级滤波。蓝色终态在换色前独立采得，随后用青色预热，再触发换回蓝色。修复侧 1／2 秒旧绿门均保持至采集结束。负的旧绿增量表示轻微低于终态。 [基线读数](baseline.json) · [修复读数](fixed.json) · [同曝光画面](comparison.png)

适用范围为两盏固定实时点灯、非烘焙阴影遮罩、实际灯表持续两条、一个颜色分量归零的当前光路。控制中环境和发光为零，运动拖影、物理参考误差及普通 Player 动态画质沿各自既有范围验收。Astra Max 复审同意采用这项修复。
