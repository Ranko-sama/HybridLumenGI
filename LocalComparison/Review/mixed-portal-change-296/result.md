# 同帧移动与改色的旧照明隔离

T3／G3 的定向组件对照使用同一已发布 MeshRenderer 网格。它移动 2.2 米并同时更新漫反射颜色，两个宽 2.18 米的来源范围互不相交，含 SDF 留边的遍历范围相交。静止接收点在两个硬域外，仍在现有影响半径内。

实际 `Scene.Prepare` 在 Release240 和 Release241 均得到合并后的 `Added | Transform | Material`。旧版的世界缓存可见性刷新标记为 0。修复后，两个端点都向原递归拒旧逻辑提供有效标记和影响半径。两个域仍拒绝旧屏幕历史，本对象的纯姿态例外标记为 0。

对照编译了实际 Scene、Scene BVH 与 ChangeRegions。Proxy 和 Unity 命令接口由现有宿主提供，首个编译缺两处替身接口，补齐后完成同输入比较。结论覆盖 CPU 分类与实际绑定载荷。残留幅度、恢复时间及普通 Player 画质继续验收。既有两室关门画面对应纯姿态事件。[纯姿态实机结果](../portal-recovery-138/result.md)
