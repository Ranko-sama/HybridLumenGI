# 精确软件近景的同界兄弟叶合并未采用

原计划 G4／G5 的固定近景软件预算。保存的 Release259 场景有 240 个三角形。按现有分组规则计算，其中 120 对同界兄弟叶可共享一次包围盒查询，模型节点数由 479 降至 239。候选保留原逐三角求交、身份和最近命中顺序。模型给出结构工作量，实际时间由下面的同源窗口裁决。
