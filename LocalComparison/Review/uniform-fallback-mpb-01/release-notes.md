Windows x64 实验性统一示例和同版可编辑 Unity 工程。

单槽普通 Lit 物体没有可用精确命中或表面卡时，现在会跟随运行时设置的均匀基础色与发光覆盖。对同一块原本发红光的板，实机白地板的反弹在设置 Renderer 绿色、设置槽 0 蓝色、清除槽覆盖后依次为绿、蓝、绿。三次更新均无需调用 `MarkDirty()`。

开启多次反弹和时间累积后，唯一发光板由纯绿切为纯蓝，受光地板的旧绿在首个蓝色帧为切换前的 7.46%，第 +30 帧为 0.285%。画册列出七个实际时点和剩余不确定性。

Windows 版直接从发布的可编辑工程 ZIP 在干净目录中构建。完整解压 Windows 包后双击 `Start-LocalRelease.cmd`。离线打开 `PictureComparison/index.html` 可查看同曝光画面对照。Unity 工程则使用 6000.0.85f1 和 URP 17.0.4，打开步骤在其根目录 README 内。
