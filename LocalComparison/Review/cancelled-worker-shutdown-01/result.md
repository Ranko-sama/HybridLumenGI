# 最后一次退出回调能收回取消中的形变网格

应用退出时，后台可能还在为一份未发布的网格计算 SDF 和表面卡。主线程已经为它创建了私有网格并预留内存。以前，只要通用 GPU 退休队列为空，主线程就可以在取消生效前返回。如果此后没有新的 Unity 回调，这份网格便错过清理机会。

Release107 在通用队列排空后，使用同一个五秒退出期限等待已取消的纯 CPU 任务。任务实际结束后，主线程才能销毁未发布的私有网格并归还预留。超过期限或销毁失败时，系统继续保留相应所有权。
