# HybridLumenGI Release107 · Windows x64

将整个 ZIP 解压到新目录，双击 `Start-LocalRelease.cmd`。单击游戏窗口后即可用键盘操作，默认进入彩墙场景。

| 查看或操作 | 按键 |
| --- | --- |
| 中性两室的远近切换 | 按 F3 进入两室，2 到远场，1 返回近场 |
| 走过两道错位门洞 | 在两室中按 F4 进入三室，从右侧开口前进，向左对准中央门，再前进。O 开闭滑门 |
| 返回原场景 | F4 从三室返回两室，F3 关闭整个房间布局 |
| 自由移动、升降与转向 | WASD、Q/E、方向键 |
| 换墙色、开关解析灯、启停门运动 | C、L、M |
| 启停形变、切换可读网格与蒙皮 | 空格、K |
| 切换软件追踪或 DXR | 4、5 |
| 离开分页范围、释放／重载分页组 | 3、B |
| 隐藏面板、记录状态、退出 | F1、F2、Esc |

在 `PictureComparison/index.html` 可离线查看颜色误差、换色与关灯残留、运动拖影、恢复过程，以及非方向和方向烘焙光照贴图的替换对照。各节标明场景、采集版本和参考画面的条件。

Unity 6000.0.85f1／URP 17.0.4，Windows x64、Mono、DX12、Linear。默认窗口 960×540，半分辨率 GI、每像素 2 条射线、4 级滤波，优先 DXR。分项 GPU 计时和显存观察默认关闭。日志位于解压目录上一级的 `LocalRelease107.log`，原生插件通知与许可位于 `Documentation`。
