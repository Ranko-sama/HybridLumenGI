# HybridLumenGI Release103 · Windows x64

将整个 ZIP 解压到一个新目录，双击 `Start-LocalRelease.cmd`。单击三维窗口后即可用键盘控制。默认视图是原来的彩墙示例。

| 操作 | 按键 |
| --- | --- |
| 进入相邻两室，或返回原布局 | F3 |
| 全开／全闭两室之间的分隔门 | O |
| 移动、升降、转向 | WASD、Q/E、方向键 |
| 近场、远场、离开分页范围 | 1 或 R、2、3 |
| 请求软件追踪、请求 DXR | 4、5 |
| 切换墙色、开关解析灯、启停原示例门运动 | C、L、M |
| 启停形变、切换网格与骨骼、释放／重载分页组 | 空格、K、B |
| 隐藏面板、写入诊断日志、退出 | F1、F2、Esc |

按 F3 时相机会回到近场，分隔门默认全开。沿地板穿过门洞可以看到光源室内的暖色发光板。留在前室按 O 切换隔门。按 L 关闭解析灯后发光面仍参与照明。导航是自由相机，不做人物碰撞。

双击 `PictureComparison/index.html` 可离线查看颜色误差、换色与关灯残留、运动拖影、收敛、白炉、零漫反射、离屏纹理和两室遮挡。本版补入同一次关门后的暖光衰减、静态光照贴图替换前后与独立直射基准的三张图，并附原始 EXR。图中的地板来自相同机位与曝光，两室开／关图是分别启动、保持固定门姿后的观测。

本机配置为 Unity 6000.0.85f1／URP 17.0.4、Windows x64、Mono、DX12、Linear。普通窗口为 960×540，GI 半分辨率、每像素 2 条射线、4 级滤波，启动时优先 DXR，面板显示实际后端。F2 日志在解压目录上一级的 `LocalRelease103.log`。原生计时插件通知与许可在 `Documentation`。
