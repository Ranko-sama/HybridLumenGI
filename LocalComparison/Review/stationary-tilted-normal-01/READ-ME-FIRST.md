# HybridLumenGI Release109 · Windows x64

将整个 ZIP 解压到新目录，双击 `Start-LocalRelease.cmd`。默认进入彩墙场景，单击窗口后可用键盘操作。

| 查看或操作 | 按键 |
| --- | --- |
| 中性两室的远近切换 | F3 进入两室，2 到远场，1 返回近场 |
| 走过两道错位门洞 | 在两室中按 F4 进入三室，从右侧开口前进，向左对准中央门，再前进。O 开闭滑门 |
| 返回原场景 | F4 从三室返回两室，F3 关闭房间布局 |
| 自由移动、升降与转向 | WASD、Q/E、方向键 |
| 换墙色、开关解析灯、启停门运动 | C、L、M |
| 启停形变、切换可读网格与蒙皮 | 空格、K |
| 切换软件追踪或 DXR | 4、5 |
| 离开分页范围、释放／重载分页组 | 3、B |
| 隐藏面板、记录状态、退出 | F1、F2、Esc |

本版修复静止斜面可能误裁成熟间接光历史的问题。固定单像素检查中，用权重 0.08 将已知黑色测量混入白色历史，输出从 0.0368000 恢复为 0.9200000。要看实际场景的颜色、关灯残留、运动拖影和恢复过程，可离线打开 `PictureComparison/index.html`，各节标有采集版本与参考条件。

Unity 6000.0.85f1／URP 17.0.4，Windows x64、Mono、DX12、Linear。默认窗口 960×540，半分辨率 GI、每像素 2 条射线、4 级滤波，优先 DXR。分项 GPU 计时和显存观察默认关闭。日志位于解压目录上一级的 `LocalRelease109.log`，原生插件通知与许可位于 `Documentation`。
