# 单个投影物切换追踪表示后的远处接收面更新

同一相机仍使用 DXR 时，单个已发布对象可能从精确三角切到 SDF／解析后备。Release197 已向近处报告这种变化，远处接收面只受长范围投影影响时仍缺局部更新信号。修复复用当前选中灯和投影资格，把该对象的阴影影响距离交给局部照明与缓存调度。

在同一 Release197 独立解压工程运行匹配对照，修复版只覆盖 `HybridLumenGIRendererFeature.cs`。实际 Unity 6000.0.85f1、RTX 2080 Ti、DXR，固定 128×64 机位。离屏裁剪板的标量 alpha 为 0.5，阈值为 0.75。停用其 MeshRenderer 后，代理继续发布并切到解析 Box。地板一直在精确表中。地板中心到灯 20 单位，连接在约 12 单位处穿过投影盒。点光范围 30，GI 追踪距离 4，方向光阴影距离 5。

| 实际录制事件 | Release197 照明半径／地板优先级 | 修复版照明半径／地板优先级 |
| --- | ---: | ---: |
| 精确裁剪板切至解析 Box | 9／0 | 34／1000 |
| 保持解析 Box | 无变化域／0 | 无变化域／0 |
| 恢复精确裁剪板 | 9／0 | 34／1000 |

上传读回中的变化域包围盒及硬几何标记保持一致，独立姿态拒旧标记和半径均为零。着色器在原包围盒内执行硬拒绝，在扩展距离内使用照明反应。两侧全局失效标记均为零，世界 epoch 为 5，Scene、owner 和几何修订保持一致。[旧版实机读数](baseline.json) · [修复版实机读数](fixed.json) · [变化域消费](../../../Runtime/Resources/HybridLumenGI/HybridLumenGIChanges.hlsl)
