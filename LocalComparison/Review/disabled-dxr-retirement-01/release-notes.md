Windows x64 实验性统一示例。将 Windows 运行包完整解压，双击 `Start-LocalRelease.cmd`。

普通 Player 显式切到软件追踪后，旧 DXR 加速结构和几何属性会在 GPU 安全退休后归还。在固定近景，RTAS 计账由 132,096 B 降至 0，硬件属性由 50,176 B 降至 0，再选择 DXR 后恢复了 20 个硬件网格。此处为逻辑资源账目。

离线打开 `PictureComparison/index.html`，可查看混合回退遮板的同曝光画面、Release112 完整门与灯路线，以及原有颜色误差、残留、拖影和恢复时间对照。默认 960×540，半分辨率 GI，2 条射线、4 级滤波，优先 DXR。
