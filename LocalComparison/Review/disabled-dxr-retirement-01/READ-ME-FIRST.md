# HybridLumenGI Release113 · Windows x64

将整个 ZIP 解压到新目录，双击 `Start-LocalRelease.cmd`，再单击窗口接收键盘输入。默认进入彩墙场景。启动配置为 960×540、半分辨率 GI、2 条射线、4 级滤波，优先 DXR。

按 4 切换到软件追踪，按 5 请求 DXR，按 F2 保存当前账目。软件接管后，已停用的硬件加速结构和属性缓冲在 GPU 安全退休后释放。离线打开 `PictureComparison/index.html`，可看混合回退遮板和完整门、灯、机位路线。

| 操作 | 按键 |
| --- | --- |
| 移动、升降、转向 | WASD、Q/E、方向键 |
| 跳到近景、远景、分页范围外 | 1 或 R、2、3 |
| 进入中性两室，切换三室 | F3，在两室按 F4 |
| 开关中央滑门 | O |
| 请求软件追踪、请求 DXR | 4、5 |
| 换墙色、开关解析灯、启停门运动 | C、L、M |
| 启停形变、切换网格与蒙皮 | 空格、K |
| 释放或重载分页组 | B |
| 隐藏面板、写状态日志、退出 | F1、F2、Esc |

画册同时收录统一示例的颜色误差、换色与关灯残留、运动拖影、恢复时间，以及 Mixed 灯的烘焙遮罩。每组图保留各自的采集版本和条件。状态日志位于解压目录上一级的 `LocalRelease113.log`。原生插件通知和许可位于 `Documentation`。
