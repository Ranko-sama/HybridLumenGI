# 非均匀镜像折面的图卡与锚点

原计划第 8 节／T4 的固定镜像代表子项通过。使用 Release254 同源工程、Unity 6000.0.85f1、DX12 和 RTX 2080 Ti。沿用既有折面捕获入口的两个共边三角，普通不透明 Lit，Cull Back，X 轴缩放为 **−0.1**，其余轴为 1。两片仍共用一张真实图卡。独立倾斜平面保留正缩放作为对照。[同源工程](../feature-disable-retirement-317/delivery.json) · [原正缩放观察](../folded-chart-facing-01/result.md)

按源三角重心给出面内世界点，并用对象矩阵的逆转置计算各自的源几何法线。生产图卡实际捕获后，分别执行按三角绑定和按位置的材质查询。生产 `HLGITrySurfacePatch` 另从单格配置读取真实覆盖锚点。[原始读回](result.json)

| --- | --- | ---: | --- |
| 镜像折面，三角 0 | 均为卡 0 | 0.99731952 | 卡 0，纹素 `(31,31)` |
| 镜像折面，三角 1 | 均为卡 0 | 0.99731958 | 同一张卡的同一锚点 |
